# 按需调查的等待、深度与修订交接

2026-11-06。复用原生 ACP 执行、FIN 预算账本、版本化报告和既有方法库。

## 等待与完成

`consult_research_agent` 仍立即返回任务身份，作者可以继续独立工作。作者调用
`read_research_agent_result` 而子任务未完成时，宿主在下一次模型派发**之前**等待。
原生 `llm/stream` 插件通过私有 `/calls/ready` 长轮询完成状态，每次只有空 JSON，
不发送大段上下文、不预留模型费用、不请求模型。完成后才允许原生流程继续，
作者再读一次取得实际意见和来源。不是强制串行所有 Agent，也不是新建调度引擎。

等待从成功工具回执恢复；失败、未知费用、权限撤销仍按原准入规则处理。取消等待
不将子任务标为成功；显式恢复保留历史失败记录，当前恢复状态清除旧 failure_code。
插件必须与 Python 接口一并部署；旧插件不具备此等待能力。`wait_seconds` 兼容旧参数。

## 研究深度

宿主 `harness_execution_bindings[execution_id].research_depth` 可选 `brief`、`standard`、
`deep`，默认 standard。它进入作者输入及其委派调查/复核输入，不改变工具权限、
实际预算和模型。此阶段提供经过验证的后端配置，尚未声称前端已有深度选择器。

brief 可交付核实的消息与解释线索；standard 查明主判断必要的关系；deep 继续检查
会改变答案的公开证据，直到能区分主要解释，或能说明合理可得资料的具体边界。
深度不是调用次数、篇幅或固定 Agent 数。已有官方披露、公开数据、替代原件是
优先查证途径；工具失败不能冒充缺失披露，也不要求穷尽互联网或取得私人合同。

## 复核到修订

自主咨询的完成回执带回任务用途和所复核稿件摘要身份。保存后复用既有
`related_wording`，将实际意见与当前相关原句并置，包括未修改的结尾；量化预览
也能读取此交接。候选只作导航，不自动证明冲突或通过，不写入财务结论。
调查任务不伪装成独立复核。历史意见不会自动成为新版通过状态。

基本指引 v13 替换中文行文段；writer v13 提供连接事实、机制和使用含义的例子；
verifier v10 将一个关键意见及其关联概括交回作者。没有新增金融关键词拒绝器、
必填表格或固定全文复核。复核工具保留原文到较合理的上下文压力点（80 万字符，
且不超过任务输入上限），替换此前 12 万字符即反复收缩回执的阈值；它仍不是
模型 token 容量保证，使用量与输入压力需实测。

## 验收边界

离线检查：等待时无 paid dispatch/预算预留；继续独立工作不被阻塞；取消/失败
不丢账；实际旧稿/意见回放能导航关联句而不改提案；深度值非法时拒绝准入。
真实检查：实际输入及插件同时更新，空历史开发验证不注入旧诊断答案；记录自主
调查、复核、重复读取、输入量、成本、最终判断与中文可读性。通过工程检查不等于
研究通过，同题优化不证明未见题迁移。

本轮实际查询回放另修正公司路由：裸大写词在长查询中须有财务/公司语境才按股票代码识别；
选举 results 不构成财务语境。完整公司名、单独代码、`$代码`、财报查询仍可进入 SEC。
这仅决定搜索入口，不自动判断来源与问题相关或替作者选择证据。

原生 harness 在进入 MCP 前发生的工具查找失败，同样立即关闭下一次付费派发准入。
加载历史会话时重放的旧失败不触发新停机。恢复反馈对照当前已授权工具名返回精确的
大小写匹配，并明确失败动作未执行；不改写原提案、不替作者保存，也不开放新工具。

后台咨询继承已准入运行的上下文，不能继承一次提交工具调用即将失效的工作记忆守卫。
每次子任务读取仍重新进入原工作区权限范围，父任务撤权继续生效。显式恢复若遇到
这种宿主范围故障，先核对该子任务全部派发均已收到且计费，再复用原响应和成功读取；
未知、未完成或截断响应不能通过这条恢复路径。

成果字段修改复用 `repair_report_fields`：有待修草稿时修改该草稿，否则修改当前已接受报告，
两者都要求当前 `base_version`，并重新执行同一套结构、来源和图表绑定校验。
校验失败保留完整候选，不改变已接受稿、版本或交付状态。不会根据平行的数值列表与来源
列表推测绑定关系。图表参数在保存工具中直接披露，`read_current_report(field="schema")`
提供模型结构生成的完整合同；图表每个点分别指定来源，宿主取数，作者负责比较与解释。

作者可在成稿前委派研究判断复核；这种真实意见也参与后续关联句导航，范围明确标为
`delegated_research_question`，无被复核报告版本，不视为新稿通过。针对已存在报告的
复核继续带原稿摘要身份。普通调查结果不转换成复核意见。

报告写入只返回由 LangGraph 原子保存的状态 `Command`，在宿主工具注册中明确标记
`checkpoint_only`。显式恢复可接续这类未完成节点的原参数，版本校验、当前权限、
来源校验照常执行，历史错误继续保留；已完成节点不再执行。工作笔记或外部写入
没有这个标记，效果未知时仍须核对，不能因为属于写工具就一律重发。

联网搜索中的付费派发受阻、历史请求未决或用量未知，会生成真正的错误工具回执，
在下一次模型派发前停止。完整搜索诊断、同批成功候选及导航仍保存；普通 403、
日期未核定、单一引擎限流不等同于计费故障，也不据此宣称信息不存在。
DS 搜索成功响应按任务复用；显式准入的恢复运行可为未决请求建立关联的新调用，
保留旧请求及预留，并继续执行总预算检查。同一运行内不自动重试新故障。
网页日期识别支持正文标题后、正文前明确标注的 publication time，要求可见日期
与 datetime 一致；不以 URL、事件日期或页脚日期代替原件发布日期。

复核后的作者恢复输入同时保留被复核历史版本、当前已保存版本及最新恢复命令。
历史意见不覆盖新的工具状态或用户指令；历史原稿不冒充当前待修改稿。
当前版本由业务状态读取，模型通过既有报告读取入口取得正文，不由运维重写提案。
