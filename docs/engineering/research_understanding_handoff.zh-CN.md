# 当前研究认识、交叉验证与前瞻综合

## 复核交接中的当前判断与重复输入

`research_working_view` 只在子结果摘要与 `assess_research_result` 的结果版本准确一致时，交接负责人原样保存的 finding、条件、反证、未决及处理状态；原调查提案保留准确回读入口。needs_work/reopened 仍是未完成或重开，不构成接受；缺少版本、版本不一致或失败的处理回执，继续保留原提案身份。该投影不自动概括正文，也不将负责人的接受升级为独立认证。

委派给模型的引用导航用 `claim_catalog/claim_ref` 共享完全相同的引用主张元数据，原始请求和报告身份不变。`source_catalog`、精确来源读取参数、全文及原报告摘要保持；不同数值权威、版本和单位继续分开。复核返回前的工具说明将 finding 的实质认识与决策影响放在前面，actions 仅承载仍影响答案的事项。真实历史两次交接离线回放分别减少约8.49%和7.68%的字符，未改原记录和报告。它不压缩已经进入原生历史的旧消息，也不证明研究判断已经改善。

## 原问题与分支结束的审改

本次审改区分停止一项取数与结束它关联的判断。深度指引、原生主负责人、子任务及验收工具共同要求：对照交办关系与实际回答，解释剩余未知影响方向、幅度、时点还是精度；有依据的范围和可比观察仍可用于条件分析。能合理收束时结束；仍可能改判且有可行分析时继续。没有可行路径时保留未完成判断及影响，不制造精确预测或无限查询。

范围调整继续使用 question/context、finding/unresolved 和当前工作笔记，不增加必填表格、固定复核链或自然语言自动拒交。负责人可以接受有用的局部结果，但仍负责原问题的重要剩余部分。复核先看新发现是否应改变答案，再核对实际稿的一致性。详细 lead、scenario_sensitivity、verifier 章节提供按困难选择的读取入口，不默认加载整套方法。

作者意见处理沿原稿件版本和准确引文绑定。未决项可以引用受影响的条件判断或相邻附注，在 rationale 解释未知及其影响；重要条件仍须对读者可见，旧错误、未采用算法和逐项调查经过无需各占一句免责声明。本文没有改变引用校验、预算、权限、原生压缩或来源真实性合同。

writer 区分阶段笔记和最终回答，补充从阶段观察到当前倾向的教学例子，并要求按自然中文表达主体、变化、理由与关键条件。本轮仅证明配置与入口的离线兼容，不能证明模型研究深度或中文质量已经改善。原始提案在复核交接中重复出现的问题仍需单独调整投影，本次提示词审改不宣称已修复该数据路径。

使用 `scripts/engineering/render_research_guidance.py --output <本地HTML路径>` 可从代码生成当前方法目录、提示词组件全文及本次审改对照。生成页不包含凭据或私有运行历史；拼装示例不是某次真实模型请求，已冻结任务的配置仍以该任务实际请求为准。

本次优化沿用原生 harness、工作笔记、咨询、计算与稿件版本，不新增研究流水线、摘要系统或金融结论拦截器。工程检查与真实研究效果分别验收。

## 2026-11-12：有依据的立场与可更新判断

最新电力题之后的讨论收敛为一个交付要求：在充分调查和可追溯事实基础上，解释当前更倾向的前景、选择理由、最强竞争解释和改判条件。预测不必等待未来实绩，但事实、假设与推断不能互换。未来反转本身不是原研究不合格的证明；应检查当时可得信息、遗漏反证和假设合理性。

离线轨迹显示，主作者实际使用 Sol xhigh，既有成功补查，也有未解决的检索障碍；同时当前工作笔记累积了旧解释与撤回记录。PWR敏感性给出了有用的价格要求，VST现金门槛仍未建立实际用途基准。不能统一归因于不愿判断、推理强度不足或上下文长度；纠错历史影响成文的因果效果仍待固定证据的真实对照。

未改变原生历史或压缩策略。最新笔记仍由模型撰写，runtime 不从自然语言推导“正确认识”。`synthesis_context` 是按需读的当前导航，已经在会话中的历史不会因本次代码更新自动消失。真正比较历史负担，需要同证据、同原题、同模型配置的受控接续；不能同时换材料、方法和推理强度再归因。

`browse_context(region="acquisition")` 保留 URL 事件，并新增 `source_url=null` 的查询事件，带 `query_key`、原查询及准确失败回执入口。只有准确相同请求的后续候选能结束该查询的无结果状态，不会清除原件访问失败或证明覆盖充分。旧日期过滤、来源/期间/单位身份及权限保持不变。旧客户端若假定每行必有 URL，需要按行身份区分；当前消费端以 JSON 导航和分页显示，未新增前端字段依赖。

离线验收以真实保存的14条搜索回执回放：保留60个URL、45条原件障碍事件和21条候选事件；新增展示7次无可用结果查询，其中3次执行故障、4次无可用结果。该数字只描述选取的搜索回执，不代表整题缺口数量。网络、DNS、原站拒绝及竞争者召回质量仍需实际路径验收，本次没有把这些外部读取宣称为修通。

研究效果验收需同时检查：支持明确判断时能否作出选择；关键原件未查时能否继续取得；资料确实无法区分时是否准确保留未知；旧判断会否回流；条件和引用是否完整。篇幅变短、措辞变强和最终保存成功均不单独构成通过。真实模型验证尚未执行。

`record_research_assessment` 新增可选自然语言 `finding`：说明实际调查建立了什么、改变了什么及决策含义，附依据入口。旧调用仍有效，缺少该字段不被当成调查失败。原 actions、来源、期间、单位和版本绑定不变；没有新增数据库表。当前认识视图从成功工具日志投影，同一笔记仅保留最新已观察版本的导航，实际阅读仍获取授权范围内的当前文本；未保存笔记不能覆盖成功记录。未调用记录工具的发现仍可能在意见正文中，不能把结构字段缺失当作“没有研究”。

委派时将此视图冻结在原 observations 中，不进入任务去重键；重复读结果不会制造新付费任务。调查结果保持“调查者提案”身份，不默认作者已接受。只读笔记能力沿父任务现有 grants 传递；没有父授权就不开放，也不允许检查者修改作者笔记和报告。

原生委派输入只提供完整稿件正文、图表和引用导航，不重复内嵌全部引用快照。每项导航保留准确来源 ID、句柄及 `read_research_source` 参数；原始快照和完整委派对象继续持久化，版本摘要仍针对原对象计算。原生会话恢复已经恢复了原始任务和消息，只追加当前接续及必要的工具恢复回执，不再追加整份稿件和调查历史。此投影不修改原生历史，也不自行生成摘要；上下文压缩仍由底座承担。

模型 HTTP 客户端的连接池复用范围为一次获准运行，结束时关闭；不跨任务共享凭据，注入的外部客户端由调用方管理。使用 httpx 原生连接池保留短时间内可复用连接，底层重试仍为零。连接故障只记录异常类型及原因链类型，不打印可能带代理凭据的异常文本；未知用量和原始回执继续保留。连接复用可以减少握手次数，不能据一次成功检查宣称网络波动已根治。

`read_saved_result` 可只读当前会话已保存的失败工具回执，保留原始错误状态，不重放失败操作，也不赋予来源权威；存储、权限检查仍走原路径。

行情来源冲突检查区分证据内容与等价读取导航：同一快照、同一窗口和相同价格正文，仅分页容量或 UTC 字符串表示不同，不形成新证据。原始回执保持不变；实际窗口、标的、来源、快照与内容差异仍拒绝合并。稿件综合和别名回读复用同一身份比较。

重复读取仅按已成功工具的准确名称与参数识别。不同分页不会合并；同一参数重读可能是在验证争议，并非死循环证据。分页综合视图不复制原件、全部笔记或旧稿正文。没有固定调用上限或来源篇数配额。

## 验证

离线验证包括：笔记更新、失败保存和旧版本回执；相同请求与不同分页；当前稿与未成稿的综合视图；子任务正面发现返回、意见版本绑定、只读权限与重复派发去重；方法章节入口和现有假设计算合同。通过只能证明工程输入与交接，不证明模型会采取正确研究动作。

同题真实对照采用空研究历史，保留原问题、截止日、价格日与资料发布，Sol xhigh 主持/最终作者，Flash high 调查。新增方法与推理强度同时变化，因此仅能评价组合效果；此题参与过开发，不能声称未见题迁移。观察核心发现、需求与竞争证据的判别作用、前瞻假设依据、判断更新与全文一致性，同时登记工具故障、重复读取、压缩、成本及时间。用户授权的自动补发不释放未知用量，不重做成功动作；连续故障或无进展须先诊断。
