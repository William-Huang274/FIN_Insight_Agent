# FinSight

A self-hosted financial research workspace for collecting documents, following an investigation and reading reports with traceable sources. Users supply their data and provider credentials.

From the repository root, run `python scripts/deployment/initialize.py` followed by `docker compose up -d --build`. Open [Projects](http://127.0.0.1:8765/workspace/projects). Live model execution requires a configured native service and provider access.
