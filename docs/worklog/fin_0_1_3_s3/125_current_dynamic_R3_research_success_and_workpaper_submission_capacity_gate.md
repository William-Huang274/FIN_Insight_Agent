authority, but compiles a 59,241-character model submission view. Every one of
the 15 reviewed Evidence rows, 19 numeric authorities, six numeric relations,
nine gaps, two reflections, task scenarios, role method and graph context is

The workpaper submission uses a provider-specific non-thinking profile with an

and the 12-field schema, not on cost or speed. R4 may perform one provider call,
zero retrieval rounds and zero S1/S2 requests. It reuses only the first three
successful R3 calls; the failed fourth call is evidence, not a reusable
completion. Any length stop, missing tool call, invalid JSON, unauthorized
reference or validator failure terminates R4 without retry.

candidate. Independent L1 and content-quality assessment must still pass before
