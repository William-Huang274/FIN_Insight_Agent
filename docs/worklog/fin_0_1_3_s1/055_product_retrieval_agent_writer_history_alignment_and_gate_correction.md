# 055｜产品、内外源检索、Agent 循环与 Writer 历史再对齐

日期：2026-08-22
范围：历史对话、权威文档和当前运行产物只读审计；产品与阶段门文档更正。0 模型、0 网络、0 付费调用、0 Runtime 代码变更。

## 为什么需要更正

1–7 已经把 Actionable Uncertainty、来源权利、定量类型、Feedback、Plan、checkpoint、StopDecision、S3 consumer 和 Workbench 接到 current 数据，但最近状态把“控制面接通”描述成了“可以直接开始动态 multi-agent live”。这遗漏了 Owner 在同一轮明确提出的三个要求：S1 必须主动覆盖内外源材料；产品要从免责声明生成器升级为研究助手；Writer 必须具有中英文、动态图表和正式排版能力。

## 对账依据

- current 1–7 materialized result：三案 12/12 zero-call；自然模型／网络／付费均为 0；DELL 为 29 Evidence、38 reported facts、27 derived metrics、21 ResearchAction。
- DELL Action 归属：16 个 S1、3 个 S2、2 个 S3；public-information gap authority 为 0。
- current Runtime Pack：29 Evidence／14 residual gaps。
- 四来源 public-context successor：IDC、Microsoft、TrendForce、HPE，36 Evidence／14 residual gaps；它是独立 successor，不是 current mainline。
- current S1 readiness：DELL 仍由 Evidence admission 阻断，MU／NVDA 仍有 candidate coverage 阻断；typed graph、learned sparse 和 multi-vector 未配置。

## 真实结论

1. 四来源纵切证明了 exact capture、解析、来源用途和准入链，不证明通用 SourceHunter 或外源研究充分性。
2. 新来源主要补了行业背景、供应机制、同业 ASP 方向和反方；没有覆盖 DELL 产品价格、销量、配置、客户部署、公共采购、渠道报价、BOM、专属供应分配和价值池等核心命题。
3. 1–7 把未完成工作变成了可追踪 Action，但没有执行 Action。S2 estimate／scenario 仍为 0，自然 Agent 也没有进行二轮查询、换源、估算或停止判断。
4. 现有 protected Writer 只证明一份历史报告的财务 L1 和引用修复；没有证明双语表达、动态交付形态、图表生成或正式 DocumentModel。
5. 因此不能直接签发付费多 Agent live；否则只是让模型更稳定地消费一份仍然稀疏且未晋升的资料面。

## 更正后的执行门

1. 冻结通用命题 CoverageState，并以 DELL 价格／配置、销量、PVM、客户需求、供应链、价值池和反方作为开发纵切。
2. 对同一命题执行 AI-free 内源 SQL／对象／原文／BM25／dense／graph 路线，明确本地 failure。
3. 执行外源阶梯：官方发行人／监管／客户／供应商，行业机构／协会／市场跟踪，产品目录／公共采购／渠道报价／客户部署，可信媒体／公开 analyst 和反方查询。
4. 完成 CandidateDecision／Evidence Gate，把 accepted Evidence 晋升 current Pack；不得把 separate successor 当成 current consumer 已使用。
5. 重编译受影响 S2，生成可复算的 derived、estimate、scenario 或诚实 typed gap。
6. 通过 Proposition Coverage／EvidencePackReadiness 后，只运行 DELL 动态单单元：从用户问题、Case、as-of 和 tools 开始，真实产生 EvidenceRequest、FeedbackReceipt、PlanDelta 和 StopDecision。
7. 单单元证明后，再扩展动态多单元／多 Agent；随后实现 Writer 的 DeliverableBrief、BilingualStylePack、VisualRequest 和 DocumentModel，最后执行 MU／NVDA／异质留出与人工内容验收。

## 责任边界

- S1 不需要在 Agent 启动前关闭全部研究未知，但 AI-free 工具资格、seed Evidence、来源阶梯和故障分型必须先成立。
- Agent 可以循环调用 S1／S2、调整计划和请求人工授权；不能修复 parser、召回、排序或 Evidence Gate 的基础设施错误。
- Harness 控制身份、期间、单位、来源权利、事实权限、预算、反馈、事件与停止，不替模型写结论。
- Skill／Graph 动态指导研究；只有 source-bound 关系可晋升稳定图，模型提出的 GraphDelta 默认只在 run 内有效。
- Writer 不自由检索或编造数字；材料不足时把可执行 ResearchAction 退回 Lead。
