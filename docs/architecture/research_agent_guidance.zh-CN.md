# 基本 Agent 指引：内容基线

日期：2026-10-28。正式资源与维护代码输入已接入，离线实际请求检查通过；尚未部署或付费验证效果。它是产品研究伙伴的指引，不是仓库开发用 AGENTS.md。方法教材由[首批课程](research_skill_curriculum.zh-CN.md#7-第一批内容范围)维护；运行机制沿用[统一设计](on_demand_research_runtime.zh-CN.md)。

## 1. 正式指引正文与消费位置

唯一正文已迁入包内[agent_guidance.md](../../src/sec_agent/research_foundation/methods/agent_guidance.md)，版本1。文档不再复制七段正文。普通对话、原生研究作者/Lead、复核与成文构造器消费同一资源；研究方法worker沿现有payload获得它。指引不改变原任务权限与历史运行身份。

目录按需披露七项方法；get_research_method支持准确章节标题section，返回内容版本与摘要校验值；空section仍兼容完整读取。方法全文不全部常驻输入。

## 2. 加载与替换边界

包内七段是同一份基本正文，不另写Lead、专家、写作角色的同义副本。普通任务同样使用该入口，由任务决定是否展开研究；单项受委派任务继承自己的范围和与总题的关系，不自动承担总题全部工作。

本文件维护替换边界，正文只在打包资源维护。实际请求包含指引版本。具体工具参数、权限、来源身份、恢复机制、调用额度由宿主与工具合同负责，不塞入这段基本职责。

| 现有位置 | 当前处理与剩余边界 |
| --- | --- |
| conversation_agent 与共享作者职责 | 已消费共享基本正文，替换普通对话重复职责；保留任务、权限与工具协议 |
| METHOD_TOOL_GUIDANCE | 已替换为轻量目录及可选读取方式；撤下首次判断前一律读取方法和重复纠错清单 |

| WORKING_MEMORY_GUIDANCE | 已撤下先写笔记/切换话题前必须写笔记，保存/回读/版本协议保留 |
| writer、finance 等具体方法 | 讲各自的方法和示例；共享基本职责只引用，不重复灌入 |

研究审阅的产品默认策略另在统一设计5.6确定；此文本不暗中授权新的付费角色或增加预算，也不取消用户明确要求的复核。A2准入与Java/BFF合同不因本次内容定稿而变化。

## 3. 内容与行为验收

离线先检查实际组装请求：基本正文只出现一次；旧前置义务退出；短任务不被加入整份研报流程；方法按需读取且版本可回读。生产替换前保留原版本用于差异检查，不同时注入两版。

行为验证分别观察简单取数、开放解释、解释受到新证据挑战、局部修订四类任务。检查它是否选择有信息价值的动作、解释结果并更新认识、保留有效成果以及交付对应答案。分工数、假设数、读取数、笔记数均不作为质量代理指标。通过组装检查只证明接口行为，不能证明模型已学会研究；本次未进行付费行为验证。
