# 018 · E3 资料目录与同源补查入口

2026-09-14；对应PRD P1/P3、技术方案E3与执行路线017后续。范围是上传/项目资料的已有导航接口；不改原件、解析正文、模型配置或金融方法，不新增平台，不重复付费跑017问题。

## 根因与实现

从017 direct真实SDK请求回读：默认outline八项其实只有四个不同文本块，section/leaf各出现一次；无preview，多个块标题相同。包含分部表的1:4不在首屏。单块read的next_offset=null只表示该选择已读完，却没有整份文档的后续块入口。资料实际可读，不能归为外部未披露；这些是影响可发现性的项目内问题，不足以单独解释模型所有错误。

复用TaskAttachmentStore、LangChain切块、现有navigate_source_nodes和MCP：

- uploads outline只列section，每块一次；search仍使用leaf，两种旧ID均可read，原文、摘要和PASSAGE身份算法不变。
- outline提供至多500字符的原文预览，仍不可引用，不作模型摘要或金融标签分类。
- outline/search/read项目增加document_navigation：在该文档的block_index、block_count、next_block_request；后者是现有SourceDocumentRequest参数。它描述文档顺序，不伪装成持久“已读/未读”状态。
- 后续扫描页转向现有inspect_image；read仍不能把视觉提示当作可引用正文。提示明确next_offset只分页当前选择，不能由null推断整份文件已检查。

本包不添加通用状态机、阅读账本或按关键词拒绝缺口的裁决器。原有项目归属、撤销检查和来源权威继续生效。新目录的offset以去重后的块计数，接续使用旧目录分页位置时应重新从offset0获取目录；已保存的来源ID和原始观察仍保留，不重写旧运行。
