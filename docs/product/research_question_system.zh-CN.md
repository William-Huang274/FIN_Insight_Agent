# 从免费材料到完整研究问题

2026-09-17；0.1.4 P1/P2/P3/P5/P6 的研究设计基线。前三轮来源实查支持本设计，但没有证明全公司覆盖或模型能力。此处按用户要求，先假设各行业能取得对应的六类材料；实际执行仍须核验题目所需覆盖。

## 1. 研究的基本单位

一项研究不是“对一家公司搜六类材料”，而是回答一个会影响判断的问题。例如“AI投入上行，哪类企业有收入增长但难以改善自由现金流，什么变化会使判断反转”。先定义对象、业务/产品、地区、时间、决策用途及竞争解释，再组合资料。

六类资料是入口，不是六个固定专家，也不是六章报告。研究方向按经营机制划分：需求为什么形成，谁有能力满足，谁取得定价权，何时兑现为收入/现金，谁承担风险，以及市场价格已要求什么。新线索可以改变题目拆分；重要义务仍需明确完成或有理由收窄。

“投资光谱”在首版指从供给、需求、融资、政策与市场定价多个方向观察同一议题：直接受益、间接受益、替代压力、瓶颈租金、融资依赖及风险承担者。不是自动荐股排名或把所有关联企业都列为受益股。

## 2. 可组合的局部问题

| ID / 局部问题 | 组合材料及实际动作 | 有用交付 | 向外展开的条件 |
| --- | --- | --- | --- |
| Q01 需求从哪里来、是否重复计数 | 客户披露/产品使用、供应商订单和收入、行业/宏观量；将同一支出沿链标记 | 最终需求、渠道补库、提前采购、资本承诺分别解释 | 销量、使用量与订单背离，追库存/取消/客户融资 |
| Q02 增长归因与周期位置 | 分部同比、可比业务同行、价格/贸易/行业数量；拆量价组合汇率并购 | 哪些增长来自行业、公司份额、口径或一次性因素 | 公司超额增长不能解释，追产品/客户变化 |
| Q03 产品竞争和替代 | 规格、同任务基准、软件/迁移、客户部署、公开价格 | 适用任务下的优势/代价及采购障碍 | 峰值优势与采用不符，追可得性/生态/成本 |
| Q04 供给可兑现性 | 产能、良率/认证信息、封装内存/设备、许可、电网与合同 | 名义产能到可交付供给的约束链和时间条件 | 上游扩产而交付受限，逐产品追最紧约束 |
| Q05 议价与价值分配 | 上下游毛利/分部利润、定价、集中度、替代方案和合同 | 谁可转嫁成本，谁可能承担爬坡/降价/存货损失 | 需求同升利润分化，追成本归属和时间滞后 |
| Q06 盈利质量与现金兑现 | 三表、附注、营运资本、资本开支/租赁、投资与税项 | 报告利润→经营利润→现金→再投资的可核桥接 | 利润与现金背离，查交易/季节性/回款和非现金项目 |
| Q07 客户采用与商业模式 | 产品收费、客户侧案例、调查/论文、评论、续费披露 | 试用/部署/付费/持续使用/净收益的阶段判断 | 使用增长但变现弱，追价格、补贴、推理成本或替换 |
| Q08 融资依赖与资本循环 | 股权、债务条款、租赁、担保、资本承诺及客户集中 | 资金来源/用途/到期和压力传导；关联交易独立辨认 | 同方兼投资人和客户，核合同与实际现金，不先认造假 |
| Q09 项目与事件兑现 | 申请、批准、订单、交付、投运、诉讼/修订和历史事件 | 当前有效状态、关键依赖、下一催化或失效条件 | 旧新闻和新文书冲突，先更新状态再改判断 |
| Q10 宏观/监管传导 | 利率、就业、价格、贸易、财政/监管正式文本及企业暴露 | 具体业务受何变量影响、方向/时滞/适用范围 | 政策宣布与企业影响不一致，查生效/豁免/替代路线 |
| Q11 机构与市场预期 | 股价/指数、13F/基金披露、资本结构、盈利与情景估值 | 风险暴露变化、事件窗口、价格隐含要求 | 股价/持仓市值与经营背离，区分数量、价格与预期 |
| Q12 风险、历史前例与反证 | 历史事故/召回/违约、客户评价、监管决定和当前控制 | 机制相似性、重要差异、可观察预警 | 仅有类比不能概率外推；新事实否定关键前提即重开 |

局部问题必须含“观察→可区分的解释→对总题的影响”。不是每题都做十二项；Lead挑选能改变总判断的分支，并说明其他项为什么不适用。拒绝执行有资料的关键比较与诚实不做无关专题是两件事。

## 3. 大类问题怎样由局部问题组合

| 大类问题 | 最小研究链 | 综合时必须解释 | 何时收口 |
| --- | --- | --- | --- |
| 产业扩张与价值归属 | Q01→Q04→Q05→Q06，Q08/Q10约束 | 终端需求怎样传到订单/供给，利润现金由谁取得；不沿链重复相加 | 关键兑现断点与受益/受损条件已区分 |
| 公司竞争力与长期盈利 | Q02+Q03+Q07→Q05→Q06，Q12挑战 | 行业增长和公司优势各解释什么，优势能否持续和货币化 | 至少比较可行替代、检验最强竞争解释 |
| 技术替代/效率革命 | Q03→Q07→Q01/Q04→Q05，Q11定价 | 单任务成本下降与总需求变化分开；替代、互补与新增需求并存 | 给可验证情景与观察指标，不强行精确需求弹性 |
| 资本周期与融资脆弱性 | Q04+Q08→Q01/Q06→Q09/Q10 | 扩产与使用错位、合同刚性、现金期限和传导路径 | 压力变量有依据，未知项以条件表达而非零风险 |
| 政策/事件的跨企业影响 | Q09+Q10→Q03/Q04→Q05/Q06 | 谁真正处于政策适用范围、谁有替代路径、时间如何不同 | 关键条款和企业暴露核对，事件与因果不混同 |
| 市场价格是否要求过强假设 | 上述相关经营链→Q11，Q12反证 | 价格要求的增长/利润/资本效率是否与可观察经营条件相容 | 明示估值假设和敏感项；不冒充共识/目标价 |

例：研究AI效率提升，先由模型技术与同任务基准识别“每任务资源下降”；再由软件收费、客户使用、云容量和设备订单研究“需求扩张能否抵消”；最后分析芯片/云/应用价值分配与估值要求。不能从一次基准直接推出整个行业资本开支崩塌或无限增长。

例：研究数据中心扩张，可沿客户合同/融资→项目许可/电网→设备供给→投运/现金链；芯片公司、服务器厂、电力设备与发电资产是按关系进入的候选。风电总装机增加本身不证明AI需求，需查具体购电/接网、时间和地域关系。

## 4. 三种验收预期如何贯穿同一报告

1. **可核判断**：材料提供清楚口径时，要求读取、比较、重算、更新状态；漏读、错单位、错误引用不能写成边界。材料可以反驳原假设，结论不必正向。
2. **条件判断**：依赖未直接观测变量时，说明条件、机制、支持/反证及敏感项。能解释“为什么、取决于什么”就是产出，不能用无根据概率包装。
3. **探索判断**：低代表性评论、早期线索或缺关键变量时，交付可检验假设、已有锚点、判别观察与下一资料，不强迫假设成为事实；连机制锚点都没有则明确不能成立。

一个大题通常同时包含三种结果，不能整篇降成“探索”来掩盖可核数字错误。验收等级由实际证据和任务决定，Agent可申请改变并说明原因，不能自行免除核心研究。

## 5. 研究回环与用户可见结果

界定问题/先验假设→核对最新可用经营底盘→形成带冲突的初步判断→围绕冲突动态委派局部研究→更新判断/补反证→独立复核重要交接和推导→Lead最终综合→留下更新触发条件。

Lead持续负责问题与判断，领域负责人负责有边界的综合、验收助手工作；查询、比较、核算和资料核验助手真正承接独立工作，不把同一巨型任务换名下派。独立复核不是更强金融基模的替身，也不是让它无限发现前面本应完成的基础错误。

用户最终看到：问题的答案、主要证据链与竞争解释、哪些已确认/哪些取决于条件/哪些待探索、最值得继续跟踪什么。执行次数与角色数不是研究完成度。

技术合同、行业方法与验证安排见[研究方法执行设计](../architecture/research_method_execution.zh-CN.md)。

## 6. 一道大题如何实际展开

以“AI基础设施扩张，哪些环节能把需求转为可持续现金”为例，初始假设只是选题入口，不能预先当成结论。

| 研究阶段 | 分派的具体问题 | 产物怎样改变下一步 |
| --- | --- | --- |
| 建立经营底盘 | 芯片、服务器、云和能源各选可比业务，核同期收入、分部利润、经营现金与资本投入；明确哪些现金只能看到集团口径 | 收入与利润同向则追持续性；增收不增利则追组合、成本、存货和价格；集团现金不能填成分部现金 |
| 解释供需差异 | 对已发现的差异分别查同任务产品能力、客户部署阶段、有效供给和许可；用客户侧与供应商侧资料交叉 | 性能与采用背离时查迁移/供货；订单与使用背离时查取消、预订和融资；项目延迟时查具体未完成条件 |
| 检验资金与兑现 | 核谁承诺付款、何时付、谁建设、资产归谁；分别读股权/债务/租赁/购电及相关披露 | 可提出融资依赖或期限错配情景；缺交易现金不能拿持仓市值变化替代，缺合同条款不能编现金时间表 |
| 挑战当前解释 | 选最能推翻主判断的同行、客户、历史事件或政策变化，查具体机制与期间 | 反证成立则改判断，弱线索则记探索任务；不为凑广度无条件搜遍所有行业 |
| 综合与跟踪 | 分开回答已发生的经营变化、兑现所需条件、仍未知的关键变量和市场隐含要求 | 重要义务完成后收口；新材料只重开受影响判断，未来监测不占作当前可补齐证据 |

资料不足时收窄的是判断精度。例如未知实际利用率仍可分析盈亏对利用率的条件敏感性，但不能声称测得该公司的利用率；只有产品规格时可判断能力边界，不能宣布实际采购份额。反之，已经有两期分部表、完整持仓数量或有效项目文书，比较和状态更新就是必须做的工作，不能以“公开信息有限”略过。
