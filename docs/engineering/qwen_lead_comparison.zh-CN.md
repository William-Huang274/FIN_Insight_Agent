# Qwen Lead 对照测试

2026-09-24。用户要求以 `qwen3.8-max` 测试相同研究问题。此页区分传输接入与研究质量；不是默认模型切换或完整研究验收。

## 固定范围

沿用行业题：“AI 的采用与资本投入，在哪些环节已转化为可验证的需求、芯片与服务器交付、云服务收入和可用电力？哪些解释最有依据，哪些仍待验证？请先做预研究并组织后续议题与优先顺序，不撰写最终报告。”

使用当前 Lead prompt、工具 schema、校验及 r21 数据和向量库；新会话不注入 DS 的旧答案、错误清单或预设专题。固定非思考模式、12 次模型调用、24 次工具操作、每次 500,000 字符及 8,000 输出 token 上限。与历史 DS129 相比，当前版本已经增加读取范围投影，并修复了笔记与独立查询的批处理；因此不是严格单因素对照。非思考模式结果不能外推 Qwen 思考模式表现。

## 接入边界

复用现有 LangChain SDK、消息历史、研究图及资料读取组合，仅增加 Qwen 模型/端点匹配与参数映射。凭据由调用方显式注入，不允许混合供应商模型共用同一凭据配置。旧 schema 和 Python 导入名称保留兼容；默认 DeepSeek 配置及前端可选项不变。接入不是通过伪装 DeepSeek 模型名称或修改返回内容完成的。

Qwen 使用 `enable_thinking`，历史 reasoning 字段保持独立，不拼入正文；非思考基线不发送 DeepSeek 专用 `thinking` 参数或 reasoning_effort。官方接口说明：[阿里云 Chat Completions](https://help.aliyun.com/zh/model-studio/qwen-api-via-openai-chat-completions)。SDK 传输与 usage 映射通过 MockTransport 验证，研究质量需另看实际产物。

开发测试使用独立进程、独立配置及原生研究图，读取当前服务的数据挂载；未将生产服务替换为 Qwen，也未执行专家或最终报告。请求前保存 TokenBudgetBasis，失败和未知请求不自动重发，公共动作与原始产物分开保留。生成数据和账户信息不进 Git。

## 评审对象

检查事实前提是否可靠、行业范围是否保留、图与原文是否被正确使用、取证任务是否可执行及依赖是否必要。工具调用数、反馈条数或专题数量不单独作为正向指标；工程校验通过不代表金融判断正确。

## 本次结果

一次原生 Lead 运行在 313.802 秒后保存计划：11 次成功模型请求，8 次资料操作（2 次目录、2 次搜索、4 次正文读取），3 次提交中前两次被拒绝，最后保存 3 项判断和 3 个专题。所有正文读取来自同一份 NVIDIA 报告，没有使用图查询。输入 408,266 token、输出 11,990 token，其中缓存命中输入 342,144 token；模型用量未知为零，无失败付费重发。此用量不包含搜索 embedding/rerank，不以其他供应商单价估算本轮费用。

在引用反馈后，模型确实补读原文，提取了报告中的收入、供应承诺和基础设施项目数据，并保留了部分合同条件。这是有效行为。但本次研究质量仍未通过：

- 未查询公用事业公司就写“库中无公用事业公司原件”。运行后的只读库核查发现 Talen、Constellation、Vistra 报告均在当前快照内可读。未检查到不能等同未收录。
- 以一项 NVIDIA 产品对中国出货的占比排除中国 AI 产业链，超出该指标的总体范围；用户问题没有要求排除中国市场。
- 单一供应商报告成为行业判断的主要依据；没有通过图或其他独立材料展开产业链，终端采用问题也被后置。
- 服务器交付取证等待云收入专题完成，未给出阻止并行收集 OEM 原始数据的必要依赖。
- 正文中的未来项目与风险提示可作为调查线索，不能单独证明当前电力限制已经影响短期容量；概述与其自身保留的项目时滞存在张力。

历史 DS129 的同题运行约 122.306 秒，8 次正文读取涉及 7 份原文，曾查询图，最终保存 4 个专题；它同样有范围和判断问题。Qwen 此次没有呈现足以支持替换默认 Lead 的改善。样本仅一题，工具反馈版本有差异，且未测试 Qwen 思考模式，因此不作为模型总体排名或正确率。

SDK 与既有 Lead 回归共 64 项测试通过，baseline 和 secrets 检查通过。默认模型、生产服务、r21 数据及向量索引保持原版本；此次没有启动专家、外部取证或最终报告。

## 思考模式对照（案例132）

用户批准分别测试 DS `high` 和 Qwen `medium`，并要求不要沿用过低输出限制。两次运行固定同一问题、研究截止时刻、r21 快照、工具代码及 prompt 哈希，使用独立新会话。没有注入前轮答案或应修正的问题，也不在运行中修改提示。新增 `medium/xhigh` 配置取值以准确表达供应商档位；两家的档位与计算量不能视作等价。

Lead 的 `max_output_tokens=null` 明确不发送客户端 `max_tokens/max_completion_tokens`，保留供应商默认及上下文限制，并检查 `finish_reason=length`。本轮查询官方文档所示默认：DS high 总输出 65,536；Qwen 默认最大输出 131,072，medium 思考档位对应 16,384。不是承诺无限生成；每次请求超时 600 秒、每家最多 12 次模型请求和 24 次工具尝试，失败及未知请求不自动重发。相关说明：[DS Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)、[Qwen Chat Completions](https://help.aliyun.com/zh/model-studio/qwen-api-via-openai-chat-completions)、[Qwen3.8-max 模型限制](https://help.aliyun.com/zh/model-studio/qwen3-8-max)。

运行前 66 项相关测试通过，含实际 SDK 的两轮模拟传输：验证思考开关、档位、客户端输出上限省略、带工具与不带工具的历史 assistant 思考字段回传、usage 中 reasoning token 保留。测试不调用付费模型。思考过程只保存在私有审计字段，不转为用户正文或事实证据。

本轮只评审 Lead 预研究，不执行专家或最终报告。模型自然提出外部来源需求时，记录其具体必要性和待核范围；不改变两边工具权限或在中途加入额外资料。与历史非思考模式相比，思考与输出余量同时变化，不单独归因于某个参数；单次同题观察不构成总体正确率。

每家均为23次工具尝试。DS首次目录请求超出条数上限并纠正；Qwen无工具拒绝。所有20次模型响应均返回独立思考字段、正常 `tool_calls` 结束，无长度截断、付费请求失败或未知模型用量。以上 token 不含检索 embedding/rerank，reasoning 已包含在输出内，不能重复加总。不同请求反复携带历史，因此累计输入不等于唯一资料量。

Qwen模型等待累计968.640秒，最后一次449.552秒；DS模型等待累计168.385秒。Qwen本次慢主要发生在模型请求阶段，不能归因为BM25或图展开；两家本次均未调用图。供应商排队/预填充/思考/生成各自耗时没有细分遥测，不能进一步断言具体瓶颈。

**研究质量判断：思考配置下均有改善，但不足以直接批准无人复核的完整研究。** Qwen从此前只读一份NVIDIA报告，扩展到微软报表/电话会/新闻稿、CoreWeave、IEA和OpenAI，主动检索付费席位、token用量与用户指标；明确区分自报、财务披露、合同容量与投运容量。没有再用单一产品对华占比排除中国市场，也未直接声称库里没有公用事业原件。其读取覆盖边界与自然质疑表述比上次更稳健。DS的行业横向覆盖较广，包括OEM、电力公司、数据中心运营商与设备公司，且把部分任务的资源排队与真正依赖分开。

仍需处理的实质问题：

- DS把自己未检索到的8月末以后材料说成未入库。固定快照的离线目录及实际读取发现CoreWeave9月17日8-K、微软9月2日附件、HPE9月2日业绩、Dell9月8日10-Q等反例。F7的2,300GW和F6的take-or-pay没有出现在它引用的已读窗口，需回读具体段落，不能以同一文件被读过代替逐项依据。
- Qwen把采用指标调查整体依赖于云收入专题，把OEM资料取证依赖于芯片客户身份，基础取证本可并行，只有后续匹配综合需要等待。担保会计条款也可先读，不必等待项目进度。其三项 `next_wave` 是候选计划；本次未运行调度器，不将文字中的“第一波”视作实际并发验证。
- 两边对电力端较弱、循环支持等提出了有价值的调查方向，但少数代表窗口不足以证明行业整体排序或循环融资已经成立。原始计划中的假设需维持待验证身份。
- 本轮均未实际查询关系图，因此只观察到跨文件研究和反馈行为，未验证“始于graph”的路线及GraphRAG增益。不能用正文阅读增长替代图检索验收。

DS自然提出Meta指引版本、CoreWeave会计线索、独立采用数据三项反馈；Qwen提出NVIDIA担保范围/截断、SpaceX与xAI主体归属两项反馈。均成功保存为待复核卡，没有自动修改图或认定数据错误。外部独立采用调查/电网接入资料属于合理后续需求，但应先核库内已有材料，再按具体证据问题补取；此次没有扩源。

共享工具还存在导航负担：空目录首页主要为机构，不能代表AI产业链全景；原文窗口可能始于句中/表中或在条件处结束，需要沿父节点或后续节点回读。应把这类入口/上下文问题与模型的推断、任务依赖问题分别归因，避免堆叠个案提示词。

本轮支持继续把思考模式用于复杂Lead规划；尚不支持仅据此切换默认模型。DS更快且横向取证较广，Qwen在采用端主动检索和边界表述上有进步，但延迟显著且依赖安排问题仍在。66项相关测试、baseline、secrets及diff检查通过。原始计划、逐次用量、疑点证据和哈希保存在本地案例132；生产默认模型、前端配置、数据和向量未改动。
