# 基本 Agent 指引：内容基线

日期：2026-11-03。正式资源由维护代码注入输入。当前版本5；版本3曾将日常交付习惯纳入基础职责，替换原交付段落；部署与行为效果须分别验证。它是产品研究伙伴的指引，不是仓库开发用 AGENTS.md。方法教材由[首批课程](research_skill_curriculum.zh-CN.md#7-第一批内容范围)维护；运行机制沿用[统一设计](on_demand_research_runtime.zh-CN.md)。

## 1. 正式指引正文与消费位置

唯一正文在包内[agent_guidance.md](../../src/sec_agent/research_foundation/methods/agent_guidance.md)，版本5。文档不复制正文。普通对话、原生研究作者/Lead、复核与成文构造器消费同一资源；研究方法worker沿现有payload获得它。指引不改变原任务权限与历史运行身份。

目录按需披露七项方法；get_research_method支持准确章节标题section，返回内容版本与摘要校验值；空section仍兼容完整读取。方法全文不全部常驻输入。

## 2. 加载与替换边界

包内资源是同一份基本正文，不另写Lead、专家、写作角色的同义副本。普通任务同样使用该入口，由任务决定是否展开研究；单项受委派任务继承自己的范围和与总题的关系，不自动承担总题全部工作。

日常交付习惯直接随基础职责进入输入：回答优先、按解释选材、主体与期间衔接、术语解释、去除重复及保留必要条件。writer v9 保留专业论证、跨底稿选材和教学示例，撤下重复的通用数字取舍/术语/小结段落。不增加成文前强制读取 skill、填写提纲、字数上限或自动复核节点；引用身份仍由原工具与渲染合同处理。

验证可从真实成文请求做单变量回放：消息、工具、模型和思考配置保持原样，只由新资源替换旧基础指引；不输入旧最终回答、人工批评或示范答案。该节点对照不能替代完整 Agent 接续、研究判断正确性或原生压缩验收。

本文件维护替换边界，正文只在打包资源维护。实际请求包含指引版本。具体工具参数、权限、来源身份、恢复机制、调用额度由宿主与工具合同负责，不塞入这段基本职责。

## 3. 内容与行为验收

离线先检查实际组装请求：基本正文只出现一次；旧前置义务退出；短任务不被加入整份研报流程；方法按需读取且版本可回读。生产替换前保留原版本用于差异检查，不同时注入两版。

行为验证分别观察简单取数、开放解释、解释受到新证据挑战、局部修订四类任务。检查它是否选择有信息价值的动作、解释结果并更新认识、保留有效成果以及交付对应答案。分工数、假设数、读取数、笔记数均不作为质量代理指标。通过组装检查只证明接口行为，不能证明模型已学会研究；本次未进行付费行为验证。

## 证据辨别与表达（2026-11-02）

基本指引 v4 在常驻职责中区分描述、解释和预测，要求判断材料能否区分竞争解释，而不是仅要求谨慎措辞。research_loop v5 与 counter v4 通过虚构教学案例解释替代机制、共同来源和分母、计算与解释的区别。详细方法仍按需读取，不增加必填计划、固定反证数量或复核链。模型保留准确引用绑定，编号和来源预览由读者界面负责。效果需以真实接续判断检验；单个开发案例不代表泛化通过。

## 从原则到可复算关系（2026-11-03）

详细方法预加载的开发案例仍出现过强排除与名为“剔除”却未扣除的调整。v5替换原认识更新段，要求关键归因检查观察量到机制的连接，并用同一已知条件下的竞争情景检验识别能力，不再仅重复“谨慎”。counter v5替换抽象反问段，给出价格与成本共同变化以及直接证据足以支持有限结论的对照；finance v10替换原营运资本/金额桥教学，补足分组账期抵消、库存批次非识别、净额调整、现金流分类的具体推导。

这些是教学修订，不是运行时的自然语言判错器，不自动改模型结论、不强制每次复核或填表。旧教材版本不同时注入，已有自定义冻结方法保持原版本。新增[开发诊断题](../../tests/fixtures/research_identification_development.json)包含明确可判断的正例，防止将“全部不能判断”误作改进。question才是模型题目，review只给评审；离线接口和算例检查不证明模型已会迁移使用，原开发案例也不作为独立测试集。

## 已识别冲突的实际处理（2026-11-03）

v6替换原意见接收、缺失表述与工作记录段落：诊断与建议解法分别检验；影响后续算法的旧前提优先验证；发现冲突后实际重算、拆开问题或撤回数量判断。research_loop v6以年度附注覆盖为例解释为何查一个关键前提比重复算术更有价值；counter/verifier v6不再把建议替换句当验收答案。finance v11增加统一总体的调整贡献教学，区分参数情景与定义变化，说明季度到年度归因不能靠免责声明成立。

不新增逐句自然语言硬规则或固定复核链。沿既有rationale与计算回执披露公式口径，精确语义仍由模型判断；机械计算展示不提供本案答案。付费验证使用同一首稿和成功材料，在独立复核及原作者干净分支观察行为，保留旧失败费用。该Amazon题已参与诊断，结果只能作开发对照，不能作泛化通过证明。
