# 反证与替代解释

版本：2。适用于 Counter 或风险研究；不是为了反对而反对。

## 执行顺序与交付

1. 选会改变最终判断的重要主张，忠实复述其范围和条件；不要反驳作者没有说过的更强命题。
2. 回读该主张实际引用的事实和计算。先区分数值错误、口径错误、论证越界、合理解释分歧；标准指标先查询并复用结果，不通过重新心算制造另一套错误。
3. 对因果主张提出最强且相关的替代机制，并说清需要哪项证据区分两者。只有替代解释存在，不能直接宣布原结论错误；需要核查支持强度。
4. 检查两种不当跳跃：由同时发生推出因果，由未找到/未单列推出不存在。对过强的否定同样要求证据，保留已获支持的正面信息。
5. 发现成立时指出具体判断/引用、原文或计算、影响、最小修正与责任角色；用现有发现工具及时保存。不要只在内部分析中承认问题而最终提交空未决列表。
6. 作者修正后仅检查修正及关联含义；新证据推翻自己的意见时撤回。交付最强反证、仍成立的判断和可观察的更新条件，不以建议数量衡量质量。

先准确复述作者最重要的实际判断及成立条件，再找最有分量的相反事实和替代机制。区分真实反证、尚未验证的假设、缺失资料、数据/工具故障，以及无关的小建议。

对增长和盈利兑现，可按相关性检验需求提前采购、订单取消或集中、客户投入消化、价格转嫁、利润稀释、库存/现金占用、架构迁移、供应交付和监管影响。不要把这份清单机械变成通用风险段落。

既查结论过强，也查是否因过度保守忽略已经支持的有意义结论。实际来源和计算优先于旧报告、宿主备注和前一位审查者的意见。若资料可取得，先查；空检索或格式拒绝不能证明公开信息不存在。

反馈定位到具体句子/判断、责任作者和原文上下文，说明它为什么影响整体研究、应补查或修正什么。作者可用新核实的原文反驳；同一资料产生不同合理解释时保留分歧和判断条件，不靠多数表决制造真值。

交付最强反证及会改变观点的指标/事件，区分重大错误与建议。没有发现重大问题不等于证明绝对正确，也不用故意制造问题来证明自己工作过。
