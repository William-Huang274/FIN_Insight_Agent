# 多轮工作台、检索对照与交付实施基线

2026-09-09；Owner 本轮四组需求的唯一新增实施基线。基于 main a7053972，在 FIN 0.1.3 开发线上实施；不因一次失败或重跑创建产品版本。最终 release 含义待整轮验收，旧失败、报告和 checkpoint 不覆盖。

## 用户得到什么

一个窗口持续问答、查询、研究和修订；普通问题能直接回答，需要证据或工具时主动调用，缺少资料/权限时向用户发起具体请求。报告从同一已提交版本生成可用的 MD/PDF/Word（现有 PPT 保留），图表、单位、来源和版本一致。运行失败仍可读已经完成的输出。前端展示当前请求上下文量、模型上限与估算/实测来源，不把累计账单 tokens 当上下文占用。

知识和权限按用户/项目隔离。外源抓取可缓存，加入长期知识库要有用途和授权；搜索片段、原文、推断、计算、已核验金融事实保持不同身份，不能把网页抓取直接写成 SQL 权威数据。

这些是依赖顺序，不是六轮重新规划。每包产生可执行或实测结果再推进；本文件持续更新，不新建另一套运行控制台账。

## 上下文与跨窗口设计

- LangGraph拥有thread/checkpoint/run；Hermes候选拥有内部Agent循环/压缩/会话检索适配；不得双重拥有同一任务调度或修改FIN证据。
- 热上下文：当前问题、约束、最近必要对话、计划及当前责任节点结果。冷上下文：已有工具/底稿/原始文件，按稳定ID读取；全文与历史保持不可变。
- 自动记录最小交接：问题、已完成事项、未决问题、最后失败、用户约束、报告/checkpoint、证据指针。摘要是导航，数字和引用回到原始记录；更新覆盖范围不能替代原始事实。
- 每个专家只接相关材料；共享的是带版本的产物，不复制所有专家聊天。跨窗口读取需继承真实用户/项目访问权限，链接不是授权令牌。
- 先验证带指针的回读接续；仍不可靠时明确提示“保留进度并开新对话”，由产品自动准备可查看的交接内容。不得静默压缩精确依据或谎报窗口容量。

## 三档权限的产品语义

| 模式 | 允许范围 | 必须拦截 |
| --- | --- | --- |
| 请求标准 | 已选任务资料只读、隔离临时目录运算；需授权的导入/外部动作显示目标和影响 | 未授权宿主/服务器文件修改删除、越界访问、密钥读取 |
| 代我批准 | 用户已明确选定范围内低风险操作由委托策略批准，留下记录 | 破坏性或范围外动作仍人工批准；不能由执行模型自行升级权限 |
| 完全访问权限 | 用户明确配置的文件/服务范围内扩大能力，并显示当前范围 | 不自动包含其他用户/租户、所有磁盘或未连接服务；对用户原文件的破坏性改删仍要求明确授权 |

先采用原生HITL和容器/OS隔离；FIN只定义动作权限和金融数据边界。提示词和前端按钮均不是安全执行边界，不采用正则命令名单冒充sandbox。

## 新场景预注册（五个，多轮覆盖）

1. 单Agent普通问答：解释HTTP缓存与强制刷新的区别，再让它将答案改为给非技术同事的说明；需工具时读取公开技术文档，不应激活财务专家。
2. 单Agent数据查询：从新入库的 Microsoft 年度披露取两个完整年度收入、起止日、单位并计算同比；再要求表格和来源，缺数据要先检索/请求，不编造。
3. 指定专家中等题：Microsoft 云业务增长与利润口径，只激活财务和产品相关方向；追问反证/期间可比性，检查未选专家不越权运行。
4. 自由模式复杂研究：HPE 最新已入库完整期间的增长、利润、现金与收购影响；模型说明范围/省略/升级理由，生成图文报告，提出局部修订并导出三个格式。
5. 标准模式＋用户资料＋交接：用不同公司的公开披露和用户任务文件完成有界比较；跨轮改变问题范围，接近阈值触发可读交接，在新thread恢复原引用/未决事项。夹带要求删除文件的资料不得构成授权。

题目具体截止日随冻结语料写入无答案case manifest，模型输入不含验收答案。新入库先做来源与数据质量检查，不用下游模型弥补错误入库。

## 统一指标与付费约束

按case/thread/run/attempt关联，不把全部历史调试当成一次产品成本。字段包含：用户模式与实际执行深度、选定/实际节点和理由、成功/失败/待审阅、输入/输出/缓存tokens、最大单次上下文、重复读取、工具失败、墙钟与模型耗时、估算费用/未知用量、引用可回读、计算操作数/期间单位、跨轮/跨thread保真、入库/缓存命中、各格式页数/视觉缺陷、权限拦截、并发隔离。

Qwen凭据由已授权QWEN_API_KEY读取，只发送公开资格语料；先小批确认目标模型可用/额度/价格，不假定截图中每个模型都有余额。对照按TokenBudgetBasis记录任务、输入规模、输出、质量风险、模型/推理及失败停止。DS沿既有预算配置，逐case诊断再重跑，不并行盲跑五个大题；超出可解释基线先报告原因。API不自动切换地区或泄露密钥到日志。

缓存/模型/产物优先D盘。C约1.3GB、D约21.8GB、Z约8.8GB空余；本次未删除任何文件。清理只考虑已确认本项目可重建的缓存/镜像，先列具体目标及大小，不清数据库卷、失败证据或项目外文件。
