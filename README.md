# FinSight Agent

FinSight 是一个可自部署的金融研究工作台。把两季财报放进同一个项目，问一句「降息后，这家银行的利息收入为什么还在增长？」。你可以跟踪研究者怎样取证，在报告里点开支撑判断的原文，也可以在下一季披露后追问，比较两版答案究竟改了什么。

## 工作台里能做什么

| 你的任务 | 在 FinSight 里的做法 |
| --- | --- |
| 持续跟踪一家公司 | 用项目归集资料、研究会话、底稿和成果。用通用对话追问手头材料，或发起正式研究，指定问题、截止日和附件。 |
| 查披露与财务数据 | 从公司资料库按公司、期间和文件类型找原文。在财务数据页查看科目、单位、期间和来源，沿派生指标回看公式和操作数。覆盖范围取决于部署者导入或接通的数据。 |
| 检索团队自己的材料 | 把文档版本发布到资料空间，关联项目并选入研究。准备好执行后即可用本地 BM25 搜关键词、读取命中段落，无需启动模型。接入向量服务和重排后可做混合检索。[组织检索指南](deploy/organization/README.md) |
| 选择研究方式和模型 | 普通研究由一位研究者成稿，再独立复核；深度研究可分派专题并汇总。个人会话支持自己的 DeepSeek 密钥，可选 V4 Flash 或 Pro。组织管理员可为指定任务开通 GPT-6.2 Sol high 主持、DeepSeek Flash 调查的组合并设置预算。[模型与预算](apps/workbench/README.md) |
| 把团队的方法交给研究者 | 在「研究配置」里编辑研究方向、角色 Skill、专家并行数和审查顺序，保存版本后应用到任务。例如，把“比较两份披露时怎样处理期间差异”写成可复用的方法。[资料比较 Skill](examples/skills/source-comparison/SKILL.md) |
| 看进度并介入调查 | 活动流显示公开进展、工具动作和已记录用量。在支持交互的运行中补充待核实的假设、请求停止，或回看历史运行的停止原因。 |
| 审阅、修订和交付 | 从报告判断打开引用快照、图表数据和计算口径。对具体底稿提交修改意见，切换报告版本比较差异；交付可选网页、Markdown、PDF、Word 或 PowerPoint。 |
| 与同事共享资料 | 在多人部署中注册账户，按组织、项目和资料空间分配权限。可以只发布某个文件版本，随后撤销共享。成员检索、读取和下载资料时按当前权限访问。 |

接入外部数据时，部署者提供相应的身份信息或密钥。可配置的入口包括美国 SEC EDGAR、韩国 OpenDART、同花顺和 Alpha Vantage。研究材料、数据授权和团队索引由使用者自行准备。[数据与部署配置](docs/public/quickstart.zh-CN.md)

## 知识库：让下一次研究找回这一次的原文

**查已导入的披露。** 打开「资料库 → 知识库」，选公司、期间和文件类型，按章节阅读披露并打开原始来源。旁边的「数据库」用于查财务科目和指标。新部署需要使用者导入资料。[打开本机知识库](http://127.0.0.1:8765/workspace/assets?view=library)

**例：把三季报留给团队，下季度还能找到当时那句话。**

1. 将带正文的文件上传到项目，搜一句原话确认正文可查找。把指定文件版本发布到组织资料空间，关联到组织项目。
2. 在组织研究准备单选中这份资料，点「准备研究执行」。这会固定本次使用的版本，可以先搜资料，再决定是否启动付费研究。
3. 在「检索本次研究资料」保留「关键词 BM25 · 本地免费」，输入「净息差」，点击「搜索资料 → 读取原文」。下图展开了同时给出两季数值的段落。下次研究可选修订后的文件，之前的研究仍指向原版本。

![从示例银行三季报中检索净息差并读取原文](docs/public/images/knowledge-search.png)

关键词检索可直接读取已绑定的正文。要按语义查找相近段落，管理员需要准备文档向量、发布索引，并在新研究中选用该版本。[启用知识库和混合检索](docs/public/quickstart.zh-CN.md#知识库与检索配置)

## 配置入口

| 你想调整什么 | 在哪里、怎样操作 |
| --- | --- |
| 个人模型与研究深度 | 打开「新建个人研究」，在「个人模型密钥」保存自己的 DeepSeek key，选择模型与普通／深度模式。保存草稿后可检查问题、截止日期和附件。[个人模型设置](apps/workbench/README.md#personal-research) |
| 团队研究方法 | 在「研究配置 → 投研 Skills」选择「增长、盈利与现金兑现」，例如写入“先核对币种、期间和计量单位，再比较两期数据”。点「保存为新版本」，选中目标任务，再点「应用保存版本」。下次运行生效。「Agent 图与编排」可以改角色绑定、并行数和审查顺序。[打开本机研究配置](http://127.0.0.1:8765/workspace/session?view=studio) |
| 组织模型组合与预算 | 管理员先配置服务商凭据、为指定执行登记预算并检查授权。研究者随后在组织草稿的「模型组合」中选择。[配置与预算检查命令](apps/workbench/README.md#provision-the-optional-organization-model-combination) |
| 登录与外部数据 | 多人登录使用 HTTPS 和本次部署的 CA。SEC、OpenDART、同花顺等来源在部署私有的 `.env` 中配置。[启动命令和变量名称](docs/public/quickstart.zh-CN.md#发起研究) |

## 从两份披露到一个可追问的判断

**同一份披露，可以从两个问题入手。** 核清一家银行的利息收入变化，两份季报就能作为普通研究的起点。如果问题扩大到「哪家银行更受益」，深度研究可以分别追查存款成本、贷款结构和估值，再比较这些差异如何影响判断。

**读报告时，顺着影响结论的数字查下去。** 示例银行的净息差从 2.1% 降到 2.0%，平均生息资产却从 100 亿元增到 110 亿元。用同一口径估算，年化净利息收入从 2.10 亿元升至 2.20 亿元。点击报告中的引用，就能核对两期数字来自哪段披露。若资产规模维持不变，下季息差降至约 1.91% 就会抵消这次增长，这给了下次追问一个具体起点。

![打开引用后，报告下方显示披露日期、原文片段和来源入口](docs/public/images/source-preview.png)

**下一季披露后再回来。** 把新季报加入原项目，追问息差是否跌破当时估算的水平。切换报告版本，就能看到新资料改变了哪项判断。

## 在本机打开工作台

准备 Docker Compose 和 Python 3.10 或更高版本，在仓库根目录运行：

```sh
python scripts/deployment/initialize.py
docker compose up -d --build
```

打开[项目工作台](http://127.0.0.1:8765/workspace/projects)。基础部署提供项目、资料和账户服务。要运行模型，按指南启用原生执行服务并配置自己的服务商密钥和预算。多人注册登录、组织模型组合及知识库索引也有独立的部署步骤。[启动与使用](docs/public/quickstart.zh-CN.md) · [本地快捷测试](scripts/dev/verify_public_checkout.py)
