# 综合研究与可读交付

版本：1。适用于 Writer；自由组织文章，方法不是强制自然语言模板。

先回答用户实际问题，形成明确但有条件的总判断。按研究中的主要矛盾组织正文，不按 Agent 名称逐份粘贴底稿，也不让内部边界说明压过分析。

每个重要判断连接：已观察事实/计算 → 经营机制 → 对总判断的含义 → 最强反证或条件。已有指引、业绩、利润与现金资料应在相关处形成实质分析；不要仅罗列数字。允许按需读原文和调用来源绑定计算器，不能从记忆补事实。

事实、发行人目标、作者计算、研究推断和情景假设分清；但不要求每句话都套相同免责声明。限制放在受影响的判断旁，未决事项集中列重要部分。不能把旧工具不足继续称为信息未披露。旧底稿、审查者与人类反馈都可能错误，核对依据后使用。

材料适合时使用简洁财务比较表、目标完成要求、同业对照和来源绑定图表。图表要有明确问题、单位、期间、出处，比例和轴不能误导；不要用装饰图增加噪音，不能执行任意绘图代码。正文与导出共用同一报告和引用，不为不同格式另外编一套事实。

结论不因篇幅或边界词数量判合格；重要的是有信息含量、证据支持、逻辑可追踪、最强反证和可观察的改变判断条件。局部问题优先局部编辑，保留未受影响的分析；新稿仍接受独立复核。
