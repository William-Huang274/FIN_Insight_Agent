# 原生 harness 按需独立调查与复核

宿主在已授权执行绑定启用 `allow_agent_consultation`，并配置现有 `answer_review_model`、价格与凭据后，主模型实际工具列表增加 `consult_research_agent` 和 `read_research_agent_result`。未配置时不披露能力，不以指引授权工具。当前独立执行器为 Sol high，主作者可继续 Flash high。

主作者提出具体问题、上下文、investigate/review 用途、可选方法 ID；可选择直接绑定当前保存稿，亦可在成稿前交接当前推断。任务返回编号，后续读取状态与结果，避免在原生 MCP 的 60 秒工具期限内等待整次研究。没有固定复核链、角色数量和必经次数。作者负责判断意见并统稿。

独立检查者始终得到已授权的 `browse_context`、`read_saved_result` 入口，不必等输入压力触发后才披露。带明确回读路径的来源选择反馈、窗口及参数校验返回原工具调用，让检查者自行修正；未分类错误及带 `execution_stop` 的派发、计量故障继续停止。原始失败不改写成成功。

日期未核定或原站拒绝的候选返回网址、失败原因和出版者查询入口，不返回未核定标题、摘要或正文，不能引用；已知晚于截止日的候选仍完全排除。真实重定向的落地页按自己的网址和日期重新核定，显式域名范围与循环检测继续生效。

报告修订入口先要求作者依据复核与补证更新对原题的判断，再决定编辑范围。事实错误可局部改，中心解释改变则可重排标题、摘要、论证及结论。增量保存不限制研究范围，也不要求重做已有调查。宿主的干净回放可显式导入哈希固定的报告版本；只有空分支可接受该导入，不覆盖当前稿，也不将旧交付状态带入新任务。

实现复用 `answer_review_provider` 的受权只读工具、逐请求预算预留/实耗/未知费用记录；子任务业务观察保存于同一内容寻址检查点存储的独立线程。读取完成结果时，准确原文及计算回执交回作者，可继续引用和计算。子任务无稿件/笔记写权限、无递归委派，无单独预算。方法正文不能提升权限。

启用咨询时，宿主给作者与各项委派分配独立派发通道，保持同一运行身份和同一预算事务。不同通道可以同时等待供应商，同一通道仍只允许一个未完成请求；任何通道出现未知用量或失败，整个运行的后续派发均停止。通道身份来自宿主，模型不能通过工具参数自行指定；未启用的旧执行保留原串行规则。不将正常在途请求误判成失败，也不通过放松总额度换取并发。

相同任务请求及相同稿件内容重复提交返回原任务；未完成和失败记录不自动重新派发。源读取/供应商故障阻止父任务下一次付费调用，取消父运行会取消未完成子任务。已取消的咨询仅在普通恢复命令和宿主签发的单次未知用量恢复授权均通过后，使用同一任务、检查点和原请求接续；供应商适配仍逐笔验证授权范围与请求指纹，旧失败和费用预留保留。其他故障需单独核对，工具不提供自动重试授权。父任务不能在咨询尚未结束时声明完成。

验收覆盖真实 ToolNode 参数注入、无递归只读工具、资料交回、重复请求复用、失败停止及实际系统指引。确定性通过只证明接线；是否主动使用、调查深度、作者是否正确更新主判断须记录真实运行。

若恢复过程在重新启动咨询之前又被中断，按作者已保存的真实委派回执定位仍未完成的任务，并核验该任务原失败运行的签名授权；不因“上一轮”编号变化丢掉任务，也不扫描恢复其他执行的咨询。监督端仅将当前运行中新发生的咨询失败作为停止信号，历史失败继续留档。

准备阶段已结束为 error 或 interrupted、且无模型审计时，必须由运维核对预算派发账本确实为零后签发准备恢复回执；不能仅凭审计文件不存在推定未调用。它不修改原运行状态，也不清除更早运行的未知费用或替代原咨询的补发授权。

正文精确替换未匹配或匹配多处属于正常编辑冲突。工具返回 `edit_not_applied`、`saved=false`、当前版本、原文候选及回读参数，整批不写入，不增加版本，不标记交付；作者自行确认位置和重新提交。近似匹配仅用于找位置，不自动改字或替换。此类反馈不触发供应商故障锁或取消并行咨询；来源绑定、权限、存储及供应商故障仍按原停止机制处理。

多次恢复沿同一咨询的实际补发键查找最新记录，成功响应仍须逐个校验输入指纹；最新未知请求须核验其原运行的单次授权，不能拿更早一次授权重复补发。恢复准备自身失败且经账本确认零派发时，凭准备回执定位保留的上一份咨询记录，再校验该记录的付费恢复授权；不改写失败记录或将未知用量归零。

若父运行停止时咨询正在执行只读工具，恢复复用公共业务桥的只读续执行入口，完成原调用后继续回放供应商响应；已完成工具不重做。未知写入效果仍禁止恢复，咨询本身没有写稿权限。

已产生失败回执的只读工具，可在用户授权的运行恢复中按原参数重新执行；必须匹配咨询记录中的失败回执及当前只读权限。旧失败留档，不因工具恢复抹除费用或放行未知供应商请求。普通委派调用仍不会自动重试。公开网页读取统一使用 `SourceDocumentRequest` 的 100–80,000 字符窗口契约，超出范围仍返回校验反馈；外层不再附加未披露的 24,000 字符上限。
