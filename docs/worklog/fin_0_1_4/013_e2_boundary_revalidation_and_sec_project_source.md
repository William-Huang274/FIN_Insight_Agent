## 产品与工程：项目可连接、保存和浏览 SEC 原始观测

采用既有`financial_facts.sec_snapshot`抓取器、Requests、SQLite、FastAPI/React，FIN只补项目归属、版本和UI投影。官方[EDGAR API](https://www.sec.gov/search-filings/edgar-application-programming-interfaces)提供CompanyFacts/Submissions，访问不需API密钥；使用宿主已有联系配置，不发送研究底稿或私有资料。官方接口仅覆盖标准分类、全公司事实等明确范围，不以缺少某标签推定公司未披露。没有引入新解析器、队列、工作流或通用数据平台。

- 项目页输入ticker/CIK，单次抓取一家公司两个固定官方URL；CIK验证复用旧抓取器，额外核对官方Submissions的ticker，禁止任意URL。
- 手动刷新保存独立版本，原件与摘要保留。SQLite记录owner/project命名空间及状态；同一更新UUID再次提交只回读原状态，不再次联网。每项目上限12次更新；失败/中断可见，旧版本不覆盖。不包含定时同步、自动恢复或生产并发限流资格。
- 选择原始指标后显示原值、单位、start/end、filed、form/accn，50行分页；大整数/小数转字符串，防浏览器数值精度损失。重复披露和修订分别保留，不自动挑“最新正确事实”。
- 日期筛选仅为filed日期不晚于指定日，不声称完整历史PIT或盘中时间资格；`fy/fp`不替代实际期间。数据读取先核对保存摘要，失败明确报错；下载也受相同owner/project和摘要检查。
- 这些是未归一化的SEC原始观测，尚未接入统一财务指标/S2/研究工具；无语义映射、权益撤销传播、成果编辑同步或自动更新。连接原件对当前项目可读，不改变旧研究权限。
