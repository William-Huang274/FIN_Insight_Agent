# 指标工作区与核心20家公司行业指标：r18交付

日期：2026-09-22。本轮完成统一时间语义、独立数据卡、历史/估值/公司比较视图、正式研究工具读取以及首批行业数据发布。验收对象是已核来源中的数据处理与可用性，不是全行业信息完整度或模型研究结论正确率。

## 产品与数据合同

公司数据库的“指标分析”包含总览、财务与经营历史、估值走势和公司对比。列表和趋势使用相同观测编号；点击数值或趋势点打开独立数据卡，查看业务范围、实际/计划状态、原始摘录和计算输入。原文窗口关闭后返回数据卡。支持显示精度选择，SQL 原值不因展示舍入而修改。

报告财年、报告阶段、期间类型、实际起止日期、交易日和可获知日期分别保存。估值按交易日浏览，不再把分母财年当成交易时间。时点指标保留已核实的季度归属；不把自然年自动当成公司财年。上下限、约数、事件和文字描述不会被画成连续的精确经营曲线。跨公司比较保留币种、业务范围、重组和报告阶段差异。

前端接口和正式 `read_source_document` 工具共同调用 `query_metrics`，使用同一不可变 SQL 版本。工具方法包含指标目录、历史、比较和单条依据读取；新报告处理仍须经过定位原页、提取、验证、未发布库构建与发布流程。详细字段及调用方法见[指标工作区合同](metric_workspace.zh-CN.md)。

- 既有来源、片段、财务点、行情和基础衍生指标的完整行内容经比对保持不变，原编号和引用身份保留。
- r18 SHA-256：`cb0ad1f56909b0a201a8fb5b1170684d9d38ab00c129863743769bf34ea6e3d5`。r17 保留用于回溯。
- 数据库、原文、截图及详细验收输出保存在部署方本地数据目录，不进入 Git，也不成为安装依赖。

## 验收和后续边界

验收包含数据库完整性/外键、旧行兼容、33条新计算的独立十进制重算，以及前端与正式工具回读。界面检查涵盖桌面、平板、手机、表格/趋势切换、多公司比较、图例、点选数据卡、来源窗口、Escape和无数据日期区间。

已通过：80项相关工程测试、类型检查、生产构建、基线和秘密扫描；正式接入修复后另跑17项相关回归（与前述测试有重叠）。前端接口20家公司历史/数据卡与共享服务逐字段相等；实际容器内正式工具45次读取通过，覆盖20家公司目录及历史、4张数据卡和1个跨公司比较，两端确认同一r18摘要。正式验收曾发现新结果类型不符合runtime既有枚举，已修复并重新构建部署后完整重验，未把中间成功读取当成最终通过。

本轮不新增Qwen向量索引、不运行DS研究推理，不把确定性回读或工程测试视为检索准确率。新行业来源正文和检索片段已保存，向量覆盖及独立检索评测应单独验收。SK hynix等公司的少量或定性记录仍是明确的后续数据工作，不因20家公司均有记录而宣布所有行业指标齐全。
