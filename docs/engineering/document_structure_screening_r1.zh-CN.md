本轮依照[冻结协议 v1](document_structure_quality_protocol.zh-CN.md)，从 64 份试审样本中先核对 6 份无当前诊断的原件。结果说明：正文分区能找到、文字能保留，与章节角色正确是不同结论。本文是已审核范围的结果，不是全库错误率或类型放行结论。

## 审核身份和范围

冻结清单身份摘要为 `4a1c1f8302ec440afc80cb7a4f2ea8cef5657556d02c4f8690b5d408df80e2bb`，选用产物沿用冻结时的分层修复结果。此次没有修改解析器、替换原产物或更改协议。原件先从只读捕获库读取并核对内容摘要；阅读原件后保存章节与角色标注，再打开冻结解析产物核对其摘要并比较。

审核者为一个 Codex 主助手，没有第二位独立审核者。样本已经参加全库诊断，不能称独立保留集。本轮有范围记录的审核为 6/64，其他 58 份保持未审；也不向 1,187 个原件或 1,742 条来源绑定外推通过比例。

三份短 8-K 核对了原 HTML 的主要章节全集、封面角色、正文与附件/签署区文本单元。不是浏览器像素级检查，也没有检查被链接附件。网页核对捕获的静态 HTML，不推断 JavaScript 运行后内容。Markdown 核对完整原文；JSON 核对完整结构和叶值。金融语义、SQL、向量和召回均不在此次范围。

## 确认的问题及最早错误环节

1. **封面排版信号被提升成内容章节。** SEC 原件中的大字号/粗体、原解析器的 heading，以及公司地址、电话、法条说明进入同一章节树。`source_structure_contract.py` 的候选提升和章节协调尚缺封面角色边界；字号或 heading 只证明排版形式，不能证明业务章节。应保留封面内容及原定位，在章节树前确定封面/文档标题/正文分区，不做公司名称或地址黑名单。
2. **搜索界面与文档标题混淆。** Amazon 原 HTML 的 `<title>` 为 `Amazon.com, Inc. - Overview`，捕获的 H2 `Site Search` 属于搜索界面。抽取元数据与该 H2 同名，被 `metadata_and_original_heading_agree` 路径确认为文档主标题。这只验证文字相同，未验证角色；原导航排除条件也未覆盖这处普通 div 中的搜索区域。应结合界面容器、输入控件、导航作用与正文区域验证，不按 `Site Search` 字符串单独屏蔽。
3. **发现入口缺少资料用途分类。** 同一 Amazon 捕获主要由全站菜单与投资者关系导航构成，却形成 609 字符 prose 预块。它可以作为发现链接的来源，不能据此伪装成业务文章；需要分开发现页和正文页的输出契约，不因“存在文本”自动认为文章提取成功。未运行 JS，不能据此声称网站本身没有其他内容。
4. **Markdown 路径只识别 ATX 标题和空行。** `document_structure_audit.py::markdown_blocks` 未用 Markdown 结构解析处理管道表格和 YAML 前置元数据。表格及许可证字段都成为 prose；应接成熟 Markdown 语法解析并保留源行区间，不能靠追加某个模型卡的正则解决。

另有明确保留的未知：8-K 中若干物理表格仍为 `physical_table_unresolved`。签署排版、注册信息和附件清单已有原文，但完整结构角色尚未落实；这不是已确认的表格数值丢失。未验证角色的表格不能直接获得财务数据表资格。

## 已核实应当保留的既有修复

- Item 与签署区的根级边界、正文继承范围，在这三份短公告的受审范围正确。
- 物理表格、原件摘要和坐标候选仍保留；没有为获得精确位置伪造坐标。文本唯一匹配与原容器唯一定位分开记录。
- 诊断预块中虽有 53 个纯空白 prose 区间，既有 `finalize_structure_prechunks.classify` 将它们全部标为 `retained_structure`。不能把诊断账本中的保留区间误报为已经进入向量索引的垃圾块。该修复本轮保持有效。

## 证据与后续处理

逐份源视图、先验标注、比较证据、产物摘要与使用限制保存在本地冻结目录的 `review-r1` 下，原始冻结计划保持不变。每份记录包括 `scope`、`unreviewed`、允许/禁止用途和未解决问题。原件、生成结果及私人执行路径不纳入 Git。

继续审核长 10-K/10-Q、其他网页、XML 和 PDF 时沿用同一口径；PDF 必须增加原页视觉核对。优先将上述角色错误纳入跨来源修复回归，修复前后保留各自结果，不能把修复后的开发样本称为独立通过。全库诊断与样本质量审核应并行记账，未审资料保持证据不足。
