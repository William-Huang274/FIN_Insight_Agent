# 从范围检查到可使用的研究判断

## 六项方法与五项执行能力的合并

| 优化项 | 产品落点 | 边界 |
|---|---|---|
| 六-1：围绕决定答案的争议组织 | 基本指引、research_loop；复用工作笔记、独立原题 | 写完分类目录不等于回答原题 |
| 六-2：委派交回调查结果 | 原 consult 入口，加 gap/consequence/next_action | 子任务不能改最终稿，可质疑上游前提 |
| 六-3：具体教学 | industry_product 企业采用到续费、生成成本到价值归属例题，目录直接披露章节 | 按需读，不把教材当本案证据 |
| 六-4：当前认识优先 | 工作笔记、acquisition、journal 事项、恢复回读 | 不重造压缩，不把旧意见默认为新版通过 |
| 六-5：有效性与深度复核 | verifier 原题范围、动作、实际修订检查 | 缺口由模型判，runtime 不按数量评分 |
| 六-6：争议驱动成稿 | writer 跨产品/公司论证，保留条件和反证 | 资料目录不固定成为报告目录 |
| 五-1：实际调查记录 | 委派冻结获取观察，保留候选/已读/障碍入口 | 未取得不等于不存在 |
| 五-2：独立检查原题 | 原题与委派分字段，同权限自主调查 | 不指定必查国家、公司或标准答案 |
| 五-3：意见变成执行事项 | record_research_assessment → 原结果入口 | 宿主绑定身份，不裁定金融判断 |
| 五-4：处理绑定实际稿件 | research_actions、respond_research_action、交付反馈 | 保存不关闭事项，反驳与明确未决合法 |
| 五-5：适时介入与结束 | 复用深度档位，重要判断/冲突/交付时考虑检查 | 无固定复核链，不按读取数禁止交付 |

这是研究执行闭环的改进，不是自动真伪裁判。主动发现调查不足及正确综合仍需真实模型验收。

## 机构研究对照与剩余差距

参照 [J.P. Morgan Private Bank 的 AI productivity 公开分析](https://privatebank.jpmorgan.com/eur/en/insights/markets-and-investing/a-brighter-productivity-outlook-for-the-ai-era)、[Morgan Stanley 全球 AI 股票映射公开解读](https://www.morganstanley.com/insights/articles/3600-stocks-map-out-ai-investing-opportunties-across-sectors)，以及其2025-07-20[完整专题报告](https://advisor.morganstanley.com/the-nicholas-group/documents/field/n/ni/nicholas-group/AiRateofChange.pdf)第30—31页的方法与限制。公开文章不等于完整客户版研究；旧完整报告不冒充2026年11月新报告。学习其论证方法，不将机构结论当答案。

本产品已有来源回读、计算、版本与模型协作。主要差距是可持续更新的比较研究与经济解释，而非继续增加搜索器或固定角色。

| 差距 | 应落到产品的能力 | 验收 |
|---|---|---|
| 样本与结论范围 | 基于既有证据对象保存问题总体、样本选择理由、时间与来源性质的比较底稿 | 客户访谈能证明某种用途，不能自动代表国家；反例能改变分组/结论，不要求全球穷举 |
| 从采用到可归属收益 | 在现有计算与笔记上做可更新驱动桥；观察值、假设、范围与来源分开，复用表格/计算执行能力 | 席位、活跃、续费、收入、服务成本、现金不互相替代；可做有依据情景而非只有免责声明 |
| 预期差与价格 | 保存预测时点快照，匹配主体/期间/口径；作者明确与共识不同的假设；反向估值按需调用 | 经营看好与当前价格划算分开，不倒灌当前预测到过去截止日 |
| 纵向跟踪与证伪 | 沿现有议题和版本维护同对象观察、原预测、改判条件及结果 | 期后区分兑现、反证和新变量，不事后改写标准 |
| 更深入的证据 | 接收授权产品试用记录、客户访谈/采购资料及样本限制，公共路径保留来源链 | 营销案例不冒充代表性客户；公开数据不足仍可给有边界的判断 |
| 综合判断与编辑责任 | 按难度配置模型，复杂题允许强模型最终成稿，使用事项/稿件对照验收 | 同题比较质量、费用、稳定性，允许有据反驳，不以接受意见数量评分 |

机构方法的启发是将推断拆成可检验的贡献与假设，区分技术受益、盈利影响和价格反映，并持续更新可比较对象。其专题方法也明确部分映射是分析师定性判断，没有完整公司收入/利润暴露量化。产品不应为了机构版式虚构精确性。

## 后续收口顺序

1. 真实验证本轮闭环：一题包含多种商业模式，另一题范围明确且证据充分。分别记漏检、误报和正确强判断，不只测会不会更保守。
2. 在公开材料与预期接口已可用的窄行业题，完成一条可复算的经营驱动—盈利/现金—预期差链，不同时开发全行业估值平台。
3. 同议题期后更新，固定原预测和口径，验证版本变化的经济意义。
4. 未见题比较模型组合与深度。冻结方法后不边测边注入答案；研究失败保留，工程故障独立记录。

第一步只证明协作闭环，后续才有依据定位为稳定支持投资研究判断的平台。无需把全面替代大行研究团队作为个人项目这一版的验收范围。
