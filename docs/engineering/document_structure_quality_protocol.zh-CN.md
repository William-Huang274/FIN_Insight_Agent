# 文档结构质量验收协议 v1

状态：2026-10-31 冻结首轮试审口径；不是当前知识库已达标声明。

目标是明确既有资料哪些可用、哪些有使用限制、哪些需要修复。不要求所有细节达到 100%，但不以整体得分抵消严重缺陷，也不把无诊断提示当作正确。

## 范围与证据身份

- 全库统计以冻结来源清单为分母，当前为 1,742 条绑定。识别质量按唯一原件统计，当前可关联 1,187 个原件；同原件多条绑定不重复计为多个样本。
- 409 条只有衍生表示的来源保留在覆盖统计中，不混入原件识别正确率。可以核验其现有表示，但不能据此恢复未经证明的原版结构。
- 冻结协议、清单、选用解析产物和代码版本；每条审核记录绑定原件摘要、派生产物摘要、页码或原位置、检查范围、审核者、日期和证据。修改金标或规则保留理由、旧版本及受影响结果。
- 当前只验原件结构与预分块。财务主体、事实期间、数值语义、SQL 取数、向量和检索效果另行验收。原文中的数字、负号、单位或脚注被丢失属于本阶段内容缺陷，不能以“财务语义另验”排除。

## 指标及分母

| 维度 | 计量方法 | v1 目标或约束 |
| --- | --- | --- |
| 内容完整性 | 原件中的正文、表格、脚注与派生结果逐项对应；单独统计遗漏、重复、改写及受影响区域 | 已确认实质丢失不得进入无条件可用状态。字符总数相等不能替代内容对应 |
| 结构角色 | 正确分类的原件结构单元 / 已审核且角色可确定的原件结构单元；缺失单元记错，不从分母删除 | 首轮目标 ≥95%；标题、正文、列表、数据表、排版容器分别报告 |
| 主要章节 Precision | 在受审范围中正确且一对一匹配的主要章节 / 输出的全部主要章节 | 首轮目标 ≥95%；重复预测不能重复获正确计数，封面地址误当章节计错 |
| 主要章节 Recall | 在受审范围中正确匹配的主要章节 / 从原件独立建立的全部主要章节 | 首轮目标 ≥95%；不以解析器找出的标题作为金标全集 |
| 小标题 | 单独报告 Precision、Recall、样本数量及错误类型 | v1 不设与主章节相同的通过线，也不以此允许已知严重遗漏 |
| 章节归属 | 满足原件所要求章节路径的正文/表格单元 / 已审核且归属可确定的单元 | 首轮目标 ≥95%；标题文字正确但父章节错误，在此记错 |
| 读序 | 原件审核得到的必要先后关系、违反数、受影响页面/区域 | 单栏和复杂版面分开；未审区域不计通过。原件本身无法确定的顺序保持未决 |
| 原定位 | 唯一定位、多个候选、无法定位、定位错误分别统计 | 不伪造唯一位置；可回读到错误原件属于严重错误 |
| 预分块 | 完整句子、章节边界、原区间覆盖、跨无关章节拼接、表头/脚注上下文关系 | 不接受已确认内容丢失或无关章节拼接；超长完整句子可以保留并标记 |

主要章节指原件中的主要内容分区，SEC 的 Part/Item 属于此范围；文档主标题、封面、目录和页眉另标角色。其他类型先依据原件确定主要/次要标题，不按解析结果的 level 倒推金标。换行、空白及已证明的碎片合并可视为等价文本，不能接受改变原意的改写。表格中的分区标题与表内列标题分别标注。

零分母报告 N/A 及原因，不报告 100%。无法判定的审核项保留数量及原因；发布指标同时显示全部受审单元、已判定单元和未决单元，不能只报排除未决后的高分。每份文档和每种类型分别报告分子/分母；给出微平均与文档宏平均，长年报不能淹没短公告的错误。结构化 XML/JSON 不适用章节指标时，验证层级、键/记录、属性和原值保留，不奖励“没有章节错误”。

## 错误分级与结果状态

| 等级 | 例子 | 处置 |
| --- | --- | --- |
| S0 严重 | 整节正文缺失，表格数值或负号丢失，跨栏拼接导致不可理解，引用指向错误原件，错误表头关系改变期间/单位解释 | 拦下受影响区域；不能可靠隔离影响时整份需修复。不得由其他维度得分抵消 |
| S1 影响使用 | 主章节漏识别、正文归错章节、目录占据正文结构、表格与关键说明断开 | 需修复；能够明确隔离时可标有条件可用，并说明允许/禁止的用途 |
| S2 轻微 | 不影响理解的空白、装饰性页眉残留、所属范围正确但次级层级偏差、保留多个候选位置 | 记录并计数；满足受审范围要求时可使用 |

最终状态为 `usable`（可用）、`conditional`（有条件可用）、`needs_repair`（需修复）、`insufficient_evidence`（证据不足）。每条必须带 `scope`、`coverage_basis`、适用用途、限制及未解决问题。没有完成审核的文档保持证据不足；抽样文档通过，不自动把同类型未审核文档改成逐份可用。

“可用”需要适用维度达到目标、内容保留有证据、没有未解决 S0/S1；只审核局部时只能声明该局部范围，不能直接给整份可用。有条件可用必须指出可用的区域/表示，例如“正文可读，复杂表格只提供原件回读”。主表头、脚注尚未验清时，不得默认该表可进入结构化取数。

## 首轮试审与后续验证

首轮是校准审核规则和发现隐藏错误的试审，不用于宣布类型或全库达到 95%。按资料类型以及“有当前诊断 / 无当前诊断”分层，每层按冻结种子选最多 4 个唯一原件；额外选每类型最多 1 个较长原件作为定向风险样本。样本不足时全部纳入，记录实际数量，不用别的类型填满。

分层概率样本与定向风险样本分开计数，不能把混合样本的直接比例当作全库错误率。类型判定优先使用已存表单字段；只能从标题推断时保留推断依据，禁止默默当成确认类型。原件类型未知时保留其他类别。

这批原件已经进入过全库修复/诊断，因此只能称“冻结试审样本”，不能称未参与修复的独立保留集。审核开始前记录公司、年份、版面/资料复杂度和既往使用情况；缺元数据不编造。覆盖不足时以追加记录补样，不替换检查失败的样本。

每份试审资料：

1. 先阅读原件，建立完整主要章节清单和角色标注，再对照输出；原件清单可以借助工具，但不能直接照抄被评测解析器结果。PDF 要核对页面视觉布局。
2. 正文详细抽查覆盖开头、中部、末尾以及章节交界、表格/脚注、复杂区域。记录检查过的页/原区间及未查部分；这些抽查不能证明整份逐字无遗漏。
3. 审核输出中的主要章节及其父子关系，记录 FP/FN、误归属、读序、定位和预分块问题。无当前诊断的样本接受同样检查。
4. 对 S0/S1 和不确定标注复查；只有单一审核者时如实记录，不能声称双人审核。辅助模型参与需要另定任务范围和预算，当前冻结不授权模型调用。

试审完成后再冻结正式验证的样本规模、类型覆盖、允许的不确定性和统计方法。正式结论必须报告样本量与抽样设计；95% 目前是质量目标，不是“小样本点估计达到就自动放行”的规则。参与修复的样本转入开发回归，另取未用于该项修复的原件验证；如果当前全库都参与过诊断，说明这个限制，不能通过改名制造独立性。

## 报告与复验

报告同时列出总库覆盖、受审范围、各类型指标分母、严重程度、影响原件/绑定数量、已修复复验和剩余未知。全库自动检查只能称对应工程检查；没有诊断、执行成功、内容守恒、人工/辅助审核和产品可用是不同证据。

发现问题先定位原件、解析表示、章节归属或预分块中的最早错误，再做通用修复。复验既覆盖失败样本，也覆盖原先正常样本。标准、金标或分母有修改时递增版本并说明原因，不在同一版结果中悄悄降低门槛。既有原件、旧解析结果及失败记录保留。
