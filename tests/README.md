# FIN 0.1.3 current baseline tests

Only tests in this directory gate the current baseline.  Historical version,
release-attempt and superseded-capability tests are preserved under
`archive/versions/**/tests` and are intentionally excluded from normal pytest
discovery.  They may be replayed only with their matching archived code and
contracts.

The active suite covers:

- DELL/MU/NVDA identity-bound Evidence Pack projection and browser routes;
- runtime-resource digest and mutation boundaries;
- admitted SEC, 8-K, market and industry data-build primitives;
- operator profiles, source bundles, saved-run inspection and subprocess jobs.
