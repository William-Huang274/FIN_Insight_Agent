# 公开调查、新闻转述与研究线索
版本：1。judgment_v2。

O1：追溯原始观察、发布者、日期和观察期间，区分受访者报告、公司说法、发布者解释与转述。转载按同一原始证据链处理。
O2：读取题目、选项、分组、作答数、招募和权重，确定各比例分母。多选、跳题、随机分表和包含关系按设计处理。相同去重总体N中两个集合a、b的交集界为max(0,a+b−N)至min(a,b)；额外包含关系进一步约束范围。加权边际估计与精确计数分别分析。
O3：逐项核对媒体转述与原表，比较历年设计和期间。使用、频率、满意、付费及留存采用各自实际测量。新增数值用来源绑定计算，保留舍入精度。
O4：判断样本发现的适用范围和外推条件。非概率抽样的模型外推需说明覆盖、选择与校准假设；按实际设计表达误差。缺失数据区分未读取、工具失败与公开披露范围。
O5：形成对本题有用的判断及值得继续调查的商业假设。具体说明什么观察支持它、竞争解释是什么、下一资料怎样改变结论。以已有线索选择后续任务，保留调查事实与推断的各自身份。
专题交付让上级能复用主张、条件、来源和计算。结构化结果与正文一致。专业问卷处理可读 survey_analysis，商业综合可读 industry_product。
