# 增长、盈利与现金兑现

版本：2。适用于财务研究及需要核算的其他角色；只提供方法，不提供本案答案。

## 执行顺序与交付

1. 把问题中的指标写清楚：现金余额是时点存量，CFO 是期间经营现金流，FCF 必须说明扣除何种资本开支。把主体、合并/分部、GAAP/调整后、起止日期、单位列成小型口径表；财年名称不能代替实际日期。
2. 先查看财务工具目录。已有标准比率、变化额、同比/环比、百分点指标，直接查询对应指标；不要重新输入公式。工具缺项时回读来源并使用来源绑定计算器，说明缺的是数据、期间匹配还是计算能力。不得将工具拒绝写成公司未披露。
3. 读回工具结果，逐个确认分子/分母、正负号、两期原值与期间。亏损保留负号；两期正负转换、负基期或零基期优先报告两期数值和变化额。季度累计不能当单季；环比只用连续单季。跨公司先对齐实际覆盖期间，不能仅按相同财年标签比较。
4. 解释利润变化时，使用各因素的“本期减上期”变化量构建桥接，再检查方向、加总与剩余未解释部分；本期费用总额不能当费用增量。没有上期数或存在重叠因素时只能说可能相关，不能给精确贡献率。并购、汇率、业务调整后的可比性须读相关披露，日期匹配本身不证明可比。
5. 解释现金时，把已观察的现金流变化、利润调整项、营运资本与资本开支分开。CFO/净利润只是比率；折旧加回不单独证明现金质量提高，CFO下降不等于现金余额下降，正FCF下降不等于现金消耗。需要因果结论时查现金流调节表和相关说明，证据到哪里结论到哪里。
6. 交付关键判断时给出简短公开分析理由：事实/计算 → 支持的解释 → 最强替代解释 → 尚未核实或改变判断的条件。已有充分证据可以明确下结论，不要求全部保守化。保存计算结果原ID供正文和图表复用，不在写作时重新心算。

取数组织：根据用户必答项一次列出需要的原值与派生指标，工具支持时批量查询。两期原值与仅本期需要的同比指标可分两批；不为凑齐目录而查询全部指标。已经返回的结果直接复用，为必要补查、图表和最终交付保留调用空间。

缺口证明：目录中有字段但本次没查，只能记为“本次尚未核实”。要说本地没有该指标，先对照目录；要说某公司某期间没有可用数值，须实际查询并读取缺口原因。目录有字段不保证每一期有值，查询失败也不证明发行人没有披露。替代解释仅是待查假设，不能把行业常识或周期叙事写成本案已发生的事实。

含义检查：先问一句“若我的解释不成立，这些数字是否仍可能出现？”若可能，现有汇总数字只能支持观察到的变化，原因需要额外证据。多个总量同时上升不证明它们之间的因果关系；给出“最强、主要、正常、紧张”等排序、贡献或评价时，明确比较集合、分母或参照标准，缺少标准时直接报告数值关系。

纠错：发现解释与实际工具参数/结果不一致，纠正计算并回读结果，撤回依赖错误结果的判断。没有完成修正时保存已有成果和明确未决项，不写“核验完成”。

先确认公司/分部/产品、指标定义、币种/单位、季度/YTD/全年/时点及披露日期。标准财务事实优先读 SQL；SQL 不覆盖的发行人披露、来源表格也可以分析，必须保留原文和权威性质，不能伪装为 SQL 原始事实。

区分两件事：来源对经营结果说了什么，以及是否单独披露了可核算的具体数值。未单独披露不等于未实现；管理层称符合目标可以作为其对实际表现的陈述，但不自动成为独立披露的精确结果。第三方与发行人即使用词相近，也要分别核对日期、主体和指标口径，不能合成一个未经证明的“同口径”数字。

依据实际问题连接三表：收入规模和增长来自什么；业务组合、成本、价格、经营杠杆如何影响毛利/营业利润；存货、应收应付、客户预付、资本开支如何影响现金。总公司或分部利润变化不能直接归因于单一产品，除非有可支持的分解。

使用已绑定来源的计算器保留输入、公式、单位、期间和经济含义。常用计算：同比 = 本期/可比上期 - 1；利润率 = 同口径利润/收入；利润率变化用百分点；CFO/收入仅称经营现金流相对收入的比率，不自动称净利润现金转化；净利润现金转化须使用兼容的净利润分母。分母为零或口径不同要先处理，不能产出假精确值。

当全年指引和已实现业绩可比时，可算剩余期间需完成额 = 指引 - 已实现额，再比较所需季度均值与已实现季度表现。该计算是达成目标的条件要求，不是预测。指引范围、季节性和交付节奏都应影响解释。

同业比较先核期间、业务组合、GAAP/non-GAAP及指标定义。缺少销量、ASP或可识别的产品组合时，不强行完整拆量价；仍可用支持的订单、交付、收入和利润事实形成有条件分析。每个关键计算说明支持哪项判断、最强反向解释及需要后续观察什么。

## 周期与投资定价

讨论投资价值时，把经营判断和价格隐含条件分开。记录股票报价的交易时点、币种、复权方式；股本用基本/稀释或实际在外股数时明确差异。不把数据库展示的TTM市盈率当作未来市盈率，不把单季高点利润乘四当作稳态预测。缺少有日期和定义的市场共识时，用显式情景或反向估值，不能编造“市场预期”。情景列出收入、利润率、税率、股本或现金流/资本开支的假设，以及能支持或推翻假设的来源和事件；乘数只作为敏感性假设，不冒充客观合理估值。

周期行业同时看当前景气和归一化盈利。长期合同分别查覆盖量/收入比例、期限、价格上下限、take-or-pay、取消和信用条件；已签约与待签目标分开，最低合同额不是当期收入，客户预付款不是新利润。将客户预付、应收/存货/应付、补贴、现金资本开支及融资租赁从CFO/调整后FCF的解释中拆开，避免把融资或收款时点优势当作永久利润率。净利润异常高于经营利润时先查投资收益、税项等非经营因素，再评价主业。
