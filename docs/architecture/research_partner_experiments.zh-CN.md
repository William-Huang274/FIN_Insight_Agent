# 从研报观察与独立实验设计研究伙伴

状态：方法研究与独立原型；不是正式 Agent 新能力的验收。2026-10-28。

本文补充既有[研究方法执行设计](research_method_execution.zh-CN.md)，不另建一套强制角色流程。独立原型在 [scripts/research_lab](../../scripts/research_lab/README.md)。本轮未改研究 runtime、服务配置或部署版本；下载原件、个人阅读记录、模型与运行输出存放在 Git 外。

## 1. 阅读范围及证据强度

完整阅读以下三个近期公开 PDF 的正文、表格、附录和披露，共 34 页，并对关键图表及异常字段核对渲染页面。它们是可公开取得的小样本，不能代表所有买方、卖方研究，也不能仅凭成稿还原作者的实际工作顺序。

| 报告 | 可直接观察的方法与定位 | 协作证据与不能推断的部分 |
| --- | --- | --- |
| [MUFG European Macro Weekly，2026-10-23，7页](https://www.mufgresearch.com/media/w4odxfqv/european-macro-weekly-23102026.pdf) | p1–3 比较实际数据、预期和不同解释；p4 用后续公布日历承接当前判断 | 引用同事专题可见；具体会议、分工与争论过程不可见。这是宏观市场评论，其监管分类不等同于股票投资研究 |
| [UOB Kay Hian Greater China Daily，2026-10-02，14页](https://www.uobkh.com.hk/strapi-uploads/China_Economics_PMI_China_Healthcare_Bi_weekly_Macau_Gaming_New_World_Development_02102026_8da422d362.pdf) | 全文含宏观、医疗、博彩、公司及技术分析。医疗 p5–7 组织事件与催化剂；博彩 p8–9 从行业数据过渡到公司差异；技术观点明确区分期限 | 不同板块有具名作者、共享目录；不能据此断定存在统一投委会或共同完成每个判断 |
| [HDFC Securities Deepak Nitrite，2026-10-26，13页](https://www.hdfcsec.com/hsl.docs//Deepak%20Nitrite%20-%20Update%20-%20Oct%2026%20-%20HSIE-202610261509270163940.pdf) | p1–10 将竞争、产能投放、价差、融资及盈利预测连起来；区分当期冲击与远期假设 | 多人署名不证明每人职责；披露提到可能使用 AI。p1 的 SELL、目标价和现价与 p11 评级定义存在表面冲突，不应当作自动正确的模板 |

另外全文阅读 [Hurst/Ooi/Pedersen，A Century of Evidence on Trend-Following Investing，2017，16页](https://www.aqr.com/-/media/AQR/Documents/Insights/Journal-Article/AQR-JPM-Fall-2017.pdf)。它不是最新研报，而是量化方法参考。跨市场、跨阶段、成本与不同宏观状态检验可见；附录明确说明两家独立供应商转录并交叉检查历史数据，这是可证实的协作。本文原型没有复现其多市场策略。

成稿可以显示“作者用了哪些材料、公开承认哪些假设、如何解释结果”，通常不能显示“先有观点还是先有证据、否决过多少方案、谁改变了谁的想法”。后者在设计时只能作为待验证假设，不能宣称已从报告提炼出真实的人类工作流。

## 2. 值得迁移的是研究操作，不是岗位名称

我们的归纳是：研究价值来自解释某个变化为什么发生、哪些因素更重要、对决策有什么影响，以及什么新观察会改变这个解释。数字核实服务于这条链，不天然构成文章的组织轴。报告中的事件罗列也未必完成这条链，因此不照单全收。

适合抽象为能力的操作包括：建立比较基准；提出竞争解释；区分事实与模型假设；连接经营变量；寻找能区分解释的新证据；更新观点；说明对用户当前决策的意义。这里的“连接”可能只是条件性解释，不都能获得因果识别。

不直接翻译为“宏观专家 → 行业专家 → 公司专家 → 审核员”的固定队列。多个问题可能只需同一作者连续使用资料和计算工具；独立分支只有在输入、产物和待解决问题可以分开时才值得委派。增加角色数量并不能证明拥有交叉验证。

## 3. 多次模型调用如何构成持续研究

每次调用都依赖实际输入，跨调用连续性依赖外部状态与输入选择。一次调用内仍能推理、使用已有知识并提出新解释；“没有人类式持久记忆”不等于不能研究。问题是，不能期待模型自行记住未再提供的证据、已接受的修订或为什么当前任务发生变化。

建议以可恢复的研究状态和实际产物作为主干：

1. **稳定目标**：用户问题、用途、时间范围、用户已作的取舍。与临时工具错误、某次复核意见分开。
2. **当前认识**：正在采用的解释及重要替代解释、关键依据和假设。允许未知、相互竞争与被推翻，不要求固定数量结论。
3. **当前工作对象**：正在分析的材料片段、表格或稿件版本，及本次新增观察。其他原件通过真实读取入口取得。
4. **执行状态**：动作的已请求、成功、失败或结果未知；已保存的变化与仍未提交的提案分开。历史检查结论绑定历史版本。

这些是系统存储和投影职责，不要求模型每轮重填四张表。正常读资料不必先更新计划；有新认识时允许局部保存，自然语言说明与引用足够时，不另造复杂字段。对上下文的整理不能由另一个摘要静默改写结论或删除反证。

输入组装保留稳定目标与当前状态，再加入当前对象、最新结果与回读入口。原始操作日志留在外部。材料保留依据正在进行的工作，不按“调用过一次工具就退出”判断。整篇报告、旧版本、旧错误不应每轮自动注入。

例如：作者读取产能资料后认为“供应扩张会压低利润”。下一次拿到成本曲线，发现低成本企业可能受益。系统保存的是新依据与作者对旧解释的更新关系；后续输入让作者同时看到仍成立的行业判断和新增的公司差异，而不是继续让旧摘要要求它证明行业整体承压。runtime 不替作者决定低成本优势是否足以抵消价格下跌。

研究推进可由“未决问题 → 有区分力的动作 → 结果 → 认识变化或明确未解决”观察。不能仅以字数、读取次数、填写率评价。没有认识变化的读取也可能必要；重复读取相同版本且无新目的才是排查对象，不应机械立即阻断。

## 4. 独立量化原型做什么

原型检验滞后收益与波动能否改善市场/现金配置；这不是把上述研报直接转成交易信号。要连接具体研报，还需要独立定义可观测代理、历史可得时间、预测期限和可交易标的，不能把“行业前景好”直接映射成下一期上涨标签。

使用 Kenneth French 公开月度数据，以 1960–1999 训练一次固定岭回归，2000–2009 验证、2010–2025 测试。四项特征、正则参数、信息滞后、基准、成本、子阶段在看结果前固定；未搜索参数或按验证结果选模型。模型不需要下载权重，也未调用 LLM API。

逐月保存特征截止月、预测、仓位、真实收益与成本。代码检查日期、缺失值、数据格式和未来数据不能改变过去特征；比较被动市场、现金、半仓和简单趋势。初次真实下载的重复年度表头导致训练前失败，修正区段解析后复用原 ZIP 成功。合成测试之前没有覆盖这个真实格式，这项失败保留在本地记录中。

结果文件同时回答预测误差、仓位暴露、成本后收益、回撤和基准差异。模型输出不自动等于交易建议，收益为正不自动等于模型有用。当前版本历史数据会被修订；留出一个月不等于验证了全部历史发布日期。研究市场代理不是可直接买卖的证券。因此原型支持流程学习与模型比较，不支持实盘收益承诺。

## 5. 我作为执行 AI 实际遇到的困难

| 实际困难 | 本轮如何处理 | 应迁移给 Agent 的支撑 |
| --- | --- | --- |
| 找到摘要不等于获得完整报告；下载可能返回 HTML | 检查文件类型、页数、全文与关键页面；未取得全文的候选不计入样本 | 文档获取状态、页级导航与图表读取，而非只有搜索摘要 |
| 叙述有吸引力，但实验定义仍不完整 | 先冻结数据、目标、时序、模型、成本与基准 | 可执行实验规格；字段尽量由数据适配器提供，语义选择由作者负责 |
| 官方数据也会更换格式、来源和历史值 | 固定原始文件、哈希、元信息，失败不自动补数 | 数据版本与可得时间分开；支持重放，缺少时间证据明确显示 |
| 预测略好与交易结果较差同时出现 | 分开评估预测、仓位、收益与风险；没有调到盈利才交付 | 多层结果展示、简单基准与失败实验保留 |
| 本轮由我选择并实现方法，有人为研究判断 | 把选择写入规格，保留失败和代码变更 | 后续用同样工具检验自研模型是否能独立执行；不能把我的结果当它已通过 |

以上是操作记录与设计推论，不是声称 AI 具有人类体验，也不能据此诊断 DS 的能力上限。没有做同输入模型对照时，不将失败归因给某个模型家族。

## 6. 建议搭建的最小框架与验证边界

优先提供一个研究工作区，加上独立的实验执行器。工作区保留可共同编辑的研究文档、来源、假设和版本；实验执行器固定规格与数据快照，运行代码并返回结果。训练/回测/统计优先使用成熟库，当前少量 NumPy 代码只是用于把第一条链做透明。

代码负责身份、版本、读写、时序对齐、计算、任务持久化、额度和失败回执；模型负责选问题、提出解释、决定下一项有价值动作及综合；人负责目标、风险偏好和实质取舍。语义复核应给出具体依据与异议，不能把“不确定”自动变成无限修订。普通阅读歧义返回候选，执行错误与研究争议分别处理。

研究转实验的草案可含：原问题与机制、可观测代理、预测目标/期限、数据可得性、基准、实验操作和结果入口。它不是所有研究必须经过的固定表单；没有合适代理时保留研究结论和待观察条件，不强制生成因子。

下一次有限验证应让自研 Agent 使用已有原型的稳定数据与工具，先解释固定结果，再完成一个预先冻结的小实验；与本轮人工 AI 执行分开记账。观察是否保留失败、区分误差与收益、正确更新观点、能在中断后复用产物。单次通过也不证明能从任意宏观判断发现盈利策略。上述框架尚未接入产品，不应在简历或验收中标成已交付功能。
