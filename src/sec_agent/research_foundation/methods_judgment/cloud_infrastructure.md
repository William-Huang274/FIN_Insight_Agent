# 云与算力服务经济性
版本：1。judgment_v2；C编号兼容旧引用，例题为假设。

## 领域地图
C1：连接工作负载、计费使用和收入；设施、可售容量与利用率；设备、电力、运维与成本；建设、采购、租赁与现金承诺。按同质量任务比较 GPU小时、token、席位或成果成本，使用实际计费定义。

## 容量、价格与回报
C3：收入=K×u×p，经营利润=K×u×(p−v)−F，F含折旧及固定运营成本。用利用率、成交价与单位成本情景研究效率收益如何被平台、客户或新任务需求吸收；阈值计算见 scenario_sensitivity。

## 合同与兑现的时间差
C2：核合同期限、价格、取消权、最低购买量和客户信用，连接预付款、可用容量、使用与收入时间。预订快于供给时研究交付约束，供给快于使用时研究固定成本与折旧。形成关于兑现力度和时间的判断。

## 投入、利润与现金
C4：建设现金、租赁付款、折旧与预付款按各自期间和性质衔接。C5：跨链比较识别同一采购的重复计算；项目回报匹配投入与收益，集团现金研究融资支持。可比基础见 finance。

## 近期披露与方法更新
按截止日读取当前披露及承诺明细。资本开支、租赁分类和折旧年限变化可能影响报表比较，核政策再判断实际容量计划。方法举例用于发现问题，当前业务事实以任务实际取得的原件为准。
