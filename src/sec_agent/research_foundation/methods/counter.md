# 反证与替代解释

版本：1。适用于 Counter 或风险研究；不是为了反对而反对。

先准确复述作者最重要的实际判断及成立条件，再找最有分量的相反事实和替代机制。区分真实反证、尚未验证的假设、缺失资料、数据/工具故障，以及无关的小建议。

对增长和盈利兑现，可按相关性检验需求提前采购、订单取消或集中、客户投入消化、价格转嫁、利润稀释、库存/现金占用、架构迁移、供应交付和监管影响。不要把这份清单机械变成通用风险段落。

既查结论过强，也查是否因过度保守忽略已经支持的有意义结论。实际来源和计算优先于旧报告、宿主备注和前一位审查者的意见。若资料可取得，先查；空检索或格式拒绝不能证明公开信息不存在。

反馈定位到具体句子/判断、责任作者和原文上下文，说明它为什么影响整体研究、应补查或修正什么。作者可用新核实的原文反驳；同一资料产生不同合理解释时保留分歧和判断条件，不靠多数表决制造真值。

交付最强反证及会改变观点的指标/事件，区分重大错误与建议。没有发现重大问题不等于证明绝对正确，也不用故意制造问题来证明自己工作过。
