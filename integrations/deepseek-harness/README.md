# DeepSeek Harness integration

These ES modules expose FinSight's dispatch, research actions, accepted results and delivery tools to a DSH worker. The native session binds each execution to an admitted model and scoped tools. Configure the execution service before starting an ACP-backed research session. See [Architecture](../../docs/public/architecture.en.md).

In a project research record, **运行动态** shows the current run's public
assistant messages and tool status. Each message preview shows up to 4,000
characters. Saved replies retain their full text. Reopening a run loads the
latest 80 saved activity entries under the reader's current permissions.
