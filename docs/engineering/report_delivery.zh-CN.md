# 报告阅读与导出

研究报告对象是内容与引用的权威输入。展示层不调用模型、不修改结论、
不把导出成功当成研究质量或人工验收通过。

## 阅读与文件

`report_delivery.export_report` 支持 HTML、PDF、DOCX、PPTX、MD。
研究会话的 `/report/export/{format}` 使用当前版本或显式 checkpoint，
工作台导出栏增加“网页阅读版”。旧格式和已有调用保持兼容。

- HTML 是自包含、无脚本的离线阅读页：响应式目录、Markdown 标题/强调/列表/表格、
  编号引用、可展开的绑定摘录、图表及数据表、来源链接。图表图片内嵌；
  阅读文件不自动请求网络，点击原文链接才会打开外部来源。
- PDF 由 ReportLab 排版：保留强调与列表，提供中文字体及符号回退、
  表头重复、图表、编号来源索引与页码。完整原文摘录在 HTML 中按需展开，
  PDF 保留来源、期间、链接及计算表达式/输入。
- DOCX、PPTX、MD 保持现有接口。修改 HTML/PDF 不意味着 Office 排版已重新验收。

显示编号与 canonical citation identity 一一对应；正文与图表数据不变。
完整来源对象继续由原报告持久化保存。未绑定外部来源的说明不能伪装成外部证据。
HTML 对原始 Markdown 禁用 HTML，元数据转义，链接只允许 HTTP(S)，并使用
禁脚本的 CSP。可选 `download_links` 仅接受 HTTP(S) 或简单同目录文件名；
调用方负责对应报告版本及权限。

## 检查与交付边界

运行 `tests/test_report_delivery.py`、`tests/test_report_reader.py`。
真实交付另需对固定报告执行：正文投影逐字核对、引用跳转、下载链接、
桌面与移动宽度检查，PDF 全页渲染检查。合成测试和版面检查不证明金融结论正确。

公开展示不应混入模型思考、恢复提示、调用额度、故障日志。报告审阅状态可以简短显示；
独立质量评价与运行复盘单独交付。运维恢复脚本、私有状态和原始调用账本不属于用户阅读页。

集成时应在共同提交上验证历史 checkpoint 导出、访问权限、来源回读及下载。
离线静态页面成功不等于工作台已部署，也不等于 Java/Python 持久任务链路已经验收。
