# 工程能力与证据 / Engineering evidence

本项目的工程与研究能力通过公开代码、可复现测试和指定样本的实际运行结果展示。
Project capabilities are demonstrated through code, reproducible tests and measured runs on specified samples.

Evaluations distinguish engineering behavior, financial judgments and human amendments, retaining the dataset and limitations of each result.
