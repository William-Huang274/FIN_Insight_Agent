# 市场预期与公开共识

市场预期沿现有研究 MCP 的 `data` 目录接入，不另建研究流程。作者和复核者通过 `discover_source_tools` 查看入口、按需读取原生参数；成功结果由既有回执及 `read_saved_result` 保存和回读。工程连通不等于预测可靠，也不表示模型已经正确完成估值或投资判断。

## 可调用组合

| 渠道 | 调用方式 | 保留的边界 |
|---|---|---|
| Alpha Vantage 官方 MCP | `read_market_expectations(symbol, dataset, offset, limit)`；dataset 为 estimates 或 earnings_history | 供应商样本中的收入/EPS预测、修订窗口、实际EPS及预期差异；不是全市场投资者预期，也不是任意历史时点数据库 |
| A股东方财富 | `query_public_data` → describe/data → `stock_profit_forecast_em` | 当前结构化表；研报数不等于分析师人数。没有核定原件单位时明确未知，不自动批准跨币种比较 |
| 港股经济通 | 同一入口 → `stock_hk_profit_forecast_et` | 同时读取原网页，保留财政年度、表头币种/倍数及更新时间。原网页和AKShare表是独立抓取，不假装是同一时刻逐行匹配 |
| 公司公开共识 | `read_public_source` 搜索或输入公开地址，再读原件 | 明确发布日期/版本；支持HTML、PDF及本次新增的XLSX。公司公布的样本及编制口径仍需作者解释 |

Yahoo预测和同花顺网页预测不列为默认兜底；它们仍可在既有公共接口目录中被发现，但本机验收遇到限流或连接失败，不能假定能接续成功。同花顺 Financial-API 官方行情工具与同花顺网页预测是不同服务，不能互相替代。

## 配置与维护

配置 `ALPHAVANTAGE_API_KEY` 后才暴露 Alpha Vantage 工具，凭据由宿主环境注入，不进入模型参数。复用[官方托管 MCP](https://github.com/alphavantage/alpha_vantage_mcp)与 MCP SDK，仅调用 `EARNINGS_ESTIMATES`、`EARNINGS` 两项只读能力，不复制供应商服务。

`FIN_PUBLIC_DATA_CACHE_ROOT` 应指向持久共享目录。SQLite 与 FileLock 保存公共响应和本机配额，按供应商及凭据摘要隔离；作者、复核者、恢复运行共享一小时缓存。默认按免费方案限制本机每日25次、相邻调用至少1.1秒；缓存读取不占新请求。服务端额度还可能被其他客户端消耗，返回的限流依旧有效。失败不缓存为数据、不自动重试；限流后冷却60秒。缓存命中保留原抓取时间。

预测分页只向模型返回所选窗口；完整供应商快照保留在当前调用回执中，不随页码丢失。缓存过期后的新请求可能形成新版本，回读旧版应使用原回执。缓存不是任务成果存储，过期缓存不会删除原回执。部署只需要既有外搜依赖，XLSX新增维护中的 `openpyxl`；安装不依赖任何开发者本机目录。

## 日期、单位和引用

Alpha Vantage 中的 date/horizon 是目标财政期间，不是预测发表日期；修订窗口也不是历史版本。早于当天的任务在派发前返回 `historical_vintage_unverified`，转用有日期的公司原件。响应未提供币种、会计口径或预测发表时间时保留空值，不能因代码属于美股就自动填USD。

AKShare可能改名时丢弃原网页的币种和量纲。FIN保留原结构化值，并独立抓取原表头和正文，不凭ticker或相近数值恢复单位。网页只有导航/免责声明而无可读表格时返回 `original_table_unavailable`；不能把网页外壳绑定成预测原件。源站读取失败与“没有预测”分开。

可引用快照有准确来源、抓取时间、内容摘要和passage身份。现有来源绑定计算器可核验原句与数值；这证明算式使用了所选数值，不证明比较口径或投资结论正确。未经原件核对的AKShare结构化表不自动成为计算依据。

XLSX由openpyxl只读解析，保留工作表、单元格地址、原始值和数字格式；公式不执行，缓存结果可能为空或过时。版本日期只从明确共识版次标题读取，不从文件创建时间、未来预测年度或任意日期猜测。HTML共识页面的明确版次标题同样进入现有日期合同。压缩包、工作表、单元格及文本规模有界，不能读取时返回明确错误。

## 验收与限制

测试覆盖MCP参数、作者/复核者入口、缓存并发合并、配额和限流、历史截止日、原句计算、单位保留、空壳页面、XLSX公式与版本。真实接口测试覆盖MSFT预测与回执回读、A股和港股预测、LSEG共识HTML及XLSX。LSEG 2026-11-03版在11月11日可读，在11月2日截止日不可见。

这些是工具及协议验收；未调用研究模型，未验证其是否主动选择正确预测口径。免费渠道没有覆盖完整历史一致预期、全部地区及所有公司，也没有替代反向估值、公司指引和价格隐含假设的研究。
