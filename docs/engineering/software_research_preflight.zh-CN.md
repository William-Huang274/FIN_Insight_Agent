# 软件与 Agent 市场研究：开题、方法入口和验收

适用于产品采用、商业化和竞争研究。复用原生 harness、现有公开来源、SEC、计算、工作笔记、咨询和稿件工具，不增加固定研究流水线。方法正文位于 `software_platforms`；案例网址、预检结论与私有运行记录不进入教学正文或模型题面。

## 方法与运行入口

基本研究指引继续负责时点背景、判断与证据的关系。`software_platforms` v2 替换原 W1—W6 概括，提供五个可按需回读的章节：产品任务与持续采用；用户声音与产品证据；从完成任务到服务经济性；收入质量与竞争价值归属；综合判断与专业产品机会。采用、用户声音及经济性是本类任务的主要入口，不要求每次全读。

宿主沿现有执行绑定设置 `research_depth: deep`，`preloaded_research_methods: []`，`include_method_section_text: false`，`research_method_sections` 列出上述相关章节及 `research_loop/研究重点与比较对象`。`section_guidance` 校验真实标题并生成准确调用参数。方法正文通过 `get_research_method` 取得，不能以未接入的虚构工具名披露能力。方法被读过不等于执行有效。

按需启用已有 `allow_agent_consultation` 和具备价格、凭据的 Sol 配置，工具名为 `consult_research_agent` / `read_research_agent_result`。可调查关键关系或检查当前稿，不强制三条赛道各分一个角色；宿主等待与完成回执沿原实现，不以模型付费轮询代替等待。任务与费用先经原准入合同，预检不得借研究预算偷偷运行模型。

## 信息工具的验收边界

分别检查搜索候选、原件读取、日期与版本、可引用回读，不用 HTTP 200 或候选数代替完成。

| 信息用途 | 现有入口 | 验收重点 |
| --- | --- | --- |
| 产品、套餐、功能及版本 | read_public_source 搜索和原件读取 | 产品文档与宣传、定价与实际支付分开；动态页面没有日期时不能冒充历史价格 |
| 使用体验、客户案例、公开调查 | 同一搜索读取入口 | 能读具体经历和研究设计；厂商案例、个人经历与独立调查分别标明，转载不算多份独立证据 |
| 经营与财务披露 | SEC 连接器、公司原站及准确文件版本 | 可读表头、附注和后续分页；集团盈利不当产品盈利 |
| 论文与研究报告 | 发布机构网页、公开 PDF 及关联原件 | 版本日期、研究期间和实际全文；摘要读取不算全文复核 |
| 上市公司价格与比较 | read_market_prices、来源绑定计算 | 报价时间、币种、调整口径；不提供未接通的实时交易或私有公司估值数据库 |

X、封闭社区、付费研报、私有客户留存、登录后的产品试用不承诺全面可得。无权限、工具访问失败、公开未披露和已读但不能区分解释是不同状态。不能让模型把前两者写成研究边界。模型选择替代原件后须再次读取和核对身份。预检发现的网站只留在验收记录，不把正确查询和已知结论当开题材料。

## 连续研究和收口

原文、来源身份和计算沿现有持久存储保留；工作笔记保存当前判断、重要条件及未决分歧，仍是可修订的作者认识。委派以有区分力的问题为单位，交回准确证据、适用范围和分歧，不把不同产品、用户或期间的片段直接拼接成行业结论。

不新建 FIN 摘要器，不把 300k 或 400k token 设为强制成稿线。监督记录实际输入 token、重复读取、新证据、判断变化、回读有效性和原生压缩事件；达到约 300k/400k 时应明确复查压力与配置，结合旧判断回流、遗漏和空转决定是否使用底座压缩。实际压缩后仍需检查当前条件和未决问题；仅检查压缩前后的长度不算通过。

研究深度由能否回答当前决策决定。对可能改变主要判断且公开可查的关系继续定向调查；宽泛搜索重复而未改变认识时应转向具体比较或收束。访问故障先处理，不能以少查资料达到成本目标。首稿若存在实质争议，可用 Sol 独立检查、Flash 修订；若作者反复无法落实，可授权强模型承担最终综合，不强制转回 Flash。

## 四项研究验收

1. 深入程度：是否取得产品任务、客户、交易或上下游的实际证据，是否清楚其代表范围；不能只增加宏观背景或公司数量。
2. 认识更新：哪些新证据支持、削弱或改变解释；没有新增比较信息时不能把差异升级成差距扩大。
3. 连续性：委派、恢复、压缩之后，来源、范围、关键条件和未决分歧仍可回读；标题、摘要与结论采用当前判断。
4. 投资连接：采用如何传导到厂商收入、成本、现金，未来预期与当前价格分别有什么依据。未取得估值资料时准确限定投资结论，不强制编造目标价。

分别保存首稿、检查意见、修订及版本差异。记录漏检、误报、新增错误、时间和费用，不用最终稿掩盖独立成稿能力。市场判断与 FinSight 产品机会分开验收；垂直专业能力的付费意愿仍需真实目标用户验证。
