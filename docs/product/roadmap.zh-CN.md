# 产品路线图

以下是 v0.1.4 的开发方向，尚未作为当前版本功能提供。

| 方向 | 预期改善 |
| --- | --- |
| 金融判断方法库 | 根据问题、行业、商业模式、准则和研究时点选择方法，明确推断需要的证据与检查步骤 |
| 按需加载局部方法 | 在具体财务判断处提示隐含假设、适用条件、可能反例和验证工具 |
| 方法更新 | 跟踪权威披露、政策与会计规则变更，记录依据、生效时间和方法版本 |
| 主动交叉验证 | 沿财务与经营关系搜索支持和反证，对有依据但未证实的假设提供风险提示与观察信号 |
| 专家协作 | 将任务交给适合的专家，并约束子任务范围、总用量和证据传递 |
| 研究时间预算 | 为分析、复核和交付预留时间，避免单个信息缺口使整份报告无限延长 |
| 多用户任务运行 | 验证排队、公平调度、暂停与接续、跨进程去重和资源隔离，支持受控网页试用 |
| 成本与质量优化 | 按任务选择工具和模型，减少重复研究；同时衡量交付质量、费用及人工修改时间 |
| 持续研究与局部更新 | 探索新披露、规则变化和用户修订驱动的定向复核，保留报告版本与判断变化依据 |

研究员负责收集决策所需的信息、解释假设与风险；投资方向、仓位和风险偏好由用户决定。效果将通过固定问题、资料和模型的对照，以及实际研究交付验证。
