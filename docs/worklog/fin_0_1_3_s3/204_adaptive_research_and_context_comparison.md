## Owner 最新授权与执行顺序

大题删除重复流程、保留必要研究和复核；小题只执行必要步骤。自由/智能调度必须由模型给出所选、略过和升级步骤的公开理由。先修接口与流程，再配合 Hermes 同题对照上下文传递正确率、精简程度。运行界面增大字体，显示模型公开分析/最终输出；失败仍保留已执行产物、最后输出和来源明确的原因。不能将触发提示或 token 记录当分析正文。

沿用原生 LangGraph 条件边、状态与结构化模型决策，不造工作流引擎；Hermes 使用官方接口/核心独立执行，不叠成现有 Agent 的单次模型调用。上下文权威仍为 FIN 来源/计算/报告合同。完整报告、失败 attempt、原 checkpoint 不覆盖；不自动接受报告，不升产品版本。

## 最小执行包与验收

1. 确定性重放15条工具错误，修来源最早接口说明/交接，保留非法参数和伪造引用拒绝。

## 产品与工程增量

- 模型通过 Pydantic `ResearchExecutionPlan` 声明 focused / integrated / extended 及选择、省略、升级理由；LangGraph 原生条件边执行。focused 限一份自足底稿，直接形成报告并独立复核；integrated 保留底稿反证/来源审查、直接 Writer、最终复核，省略 Synthesis/ResearchVerifier；extended 仅因独立综合职责而保留额外层。没有公司名、关键词或字符数分流规则。用户明确关闭多 Agent 的单模式仍标记未独立审阅。
- exact_period_end 参数提示修到 MCP 接口；未知完整日期用明确财年筛选。读取接口与计算器复用当前会话已观察来源，不把新 SQL 来源误判为未知。严格引用、来源与提交形状校验仍保留。
- 真实大题发现三次 Writer 拒稿：猜测短 claim ID、混淆 paper 与 branch 顺序、图表把 claim 当 source。后补目录完整 `citation_ids`、去掉固定示例编号、错误返回受影响底稿的真实标识；不自动猜对应关系。后补修复已确定性测试，未再付费重跑整案，不能把这次调用下降归因于它。
- 最终复核获得已完成的公开底稿审查记录；修订复核获得标准 difflib 生成的报告/图表差异和前次发现，要求说明重开旧研究的实质理由。公开审查意见不成为证据，不传递跨 Agent 私有推理。该后补接续已通过原生图测试，真实节费幅度尚未测量。
- 公开审计保存普通模型回复和明确提交的研究正文，在提交拒绝/截断前保留候选输出。原生 checkpoint 的失败经 BFF 投影为安全错误代码/解释，前端区分模型正文、候选提交、系统错误。正文16px、调用14px并提高正文对比度；仍是逐事件公开活动，不宣称逐 token 私有思维链。
- 203/A5 历史失败原本存有最终提交正文。一次诊断从指定旧审计只提取明确的 SubmitWorkpaperAction 正文，生成独立 `public-output-recovery.json`，不覆盖 checkpoint/原审计。原生实际错误为 research_bundle_invalid_citations 下的旧 q1_issuer_narrative_source_required；该旧范围门槛在203已修，恢复产物不把旧失败改成成功。界面现可看完整 NVIDIA 底稿及交接校验失败说明。
