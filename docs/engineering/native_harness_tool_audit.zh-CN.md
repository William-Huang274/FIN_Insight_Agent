# 原生 harness 业务工具边界审查

本审查针对固定 DS Harness / ACP 所实际收到的 FIN 工具，不将旧系统全部工具
默认视为已接入。依据包括真实供应商请求、业务 checkpoint、上游 MCP 文本渲染代码、
维护代码和无模型回放。通过工程检查不等于研究判断正确或真实压缩已验收。

## 根因与职责

旧执行路径使用 `source_result_view` 生成模型视图；原生 MCP 桥直接返回完整业务
回执，绕过了该投影。上游负责消息历史和压缩，不知道 FIN 来源对象中哪些字段是
重复的目录元数据。修复是在工具边界复用同一个展示投影，而非恢复旧摘要调度或
按研究阶段删除历史。固定上游 MCP 客户端只向模型渲染 `content`，不能将
`structuredContent` 的磁盘重复算作模型输入重复。

原桥的回执 ID 只在 `structuredContent`，现在 `content` 中也包含 `receipt_id`、
状态、结果及实际可用的原始回读入口。原始 ToolMessage 与 artifact 不修改；
来源权限、计算和成果绑定仍消费原始记录。成功保存和接受/交付仍分别表示。

## 实际工具覆盖

原真实请求包含16个 FIN 工具，以及上游3个 MCP 资源工具。以下逐组审查了
参数、模型返回、原始存储、回读和权限/错误处理；不是每个工具都有本案例的真实
模型调用。未使用的写入能力由版本/故障/恢复夹具验证。

| 工具 | 检查与处置 |
| --- | --- |
| `read_source_document` | catalog/outline/search/read 共用来源展示。完全相同的组织来源、检索回执只出现一次；同文档原始来源的相同字段共享，差异、节点定位和读取参数保留。目录不变成证据。显式小窗口允许100字符起，保留分页/整块边界反馈。 |
| `calculate_research_metric` | 相同来源溯源对象按引用共享；每个操作数的原句、字面值、来源ID、期间/单位、表达式、结果和语义未验证标记保留。原计算artifact不去重、不改写。 |
| `read_research_source` | 只恢复选定来源及计算依赖，当前授权检查不省略；补入历史目录，使回执可发现。 |
| `browse_context`、`read_context_turn` | 元数据目录12项/页、公开消息6000字符/页；不展示私有推理，不执行检索API，不把历史助手文字当事实。 |
| `read_saved_result` | 按准确回执ID和可选JSON pointer读原始记录，默认6000、最多24000字符；不会重新执行原工具。返回当前JSON对象的有界字段目录、准确指针和短标量原值，避免为寻找结果猜字符位置。指针/字符位置始终针对原始回执，不针对共享字段后的模型视图。 |
| `get_research_method` | 空ID返回方法目录，支持具体章节；方法与来源权限分离，不为减少体量删掉用户已要求的教学内容。 |
| `SearchWorkingNotes`、`ReadWorkingNote`、`WriteWorkingNote` | 当前接入禁用远程笔记向量调用。目录只带预览，正文分页；保存返回ID/版本，不回传整篇。保留同标题版本冲突与append/replace语义，不要求每步写笔记。 |
| `save_research_report`、`repair_report_fields` | 校验失败保存未接受草稿，只修变化字段；新增准确草稿回读，错误回执返回该入口。保存不代表交付或独立复核。 |
| `read_current_report`、`edit_research_report` | 区分已接受稿/待修草稿、版本和字段；默认返回未转义正文窗口，供精确局部替换，不再把序列化JSON片段当正文。仍保留field=all兼容读取。 |
| `deliver_working_note`、`deliver_current_report` | 仅按宿主已批准交付意图披露对应动作，避免向回答任务暴露必然失败的交付命令；不放宽准入。回答任务仍可保存有用底稿或报告草稿。 |

上游资源列表/模板/读取工具仍由上游维护。公开网络补查的显式准入见下节；
SQL、按需委派和独立复核不因本次工具展示修复自动开放。

## 引用、查询覆盖与公开补查

原生桥以已读取的准确来源 ID 派生稳定 `REF-` 句柄；句柄仅是展示和输入别名，
计算、成果校验与持久回执仍使用原 ID。唯一匹配的旧省略写法可以恢复；多义或
未知句柄返回明确反馈，不按标题猜原文。检索候选不获得可引用句柄。回答展示保留
准确绑定与未解析列表，原生回答原件另存，不能用补全引用替代判断正确性。

目录和搜索回执标明本次查询范围、分页和可用后续工具；无命中不自动升级为
库内缺失或公司未披露。宿主在已经获得授权的任务绑定中设置 `allow_public_web`
后，接入现有 `read_public_source` 搜索/抓取能力，模型自行决定是否补查。
有明确截止日的工作台公开搜索在向模型展示候选前核对日期。SEC 附件使用同一 accession 的申报索引日期，其他页面尝试从出版方正文定位发布日期。无法确定日期或晚于截止日的候选不展示标题、摘要及回读标识；可换查同一事件的有日期原始公告。搜索预览不进入历史证据，只有读取获准原文后才生成引文，外部原文不升级为 S2 数值事实。此约束不提供可变网页的历史版本保证，未归档的动态序列仍需单独核对数据版本。
发现候选按任务保存，恢复时重绑定当前运行身份；已读原文、捕获摘要和计算依赖
从可信工具记录复用，当前组织授权仍独立检查。原始内部回执不重复塞入模型正文。

研究指引与财务方法分别承担简短职责说明和具体教学：例如用虚构营运资本案例
解释为什么稳定的应收/收入比例不能单独排除账期或渠道变化。局部复核围绕
具体推断和可能改变判断的证据，不强制启动完整复核链，也不由规则替作者改结论。

## 出错前接续的隔离验收

宿主可用 `isolated_receipt_replay` 配合哈希固定的 `legacy_receipt_import`，
从真实业务 checkpoint 恢复到错误生成之前。使用独立业务账本、原生会话和笔记
空间，原运行完整保留；后来的外层回答不会初始化到新分支。回放导入准确原文、
计算和调用记录，不手改提案、不注入错误答案清单。此能力属于运维验收，不能由
浏览器传任意文件路径启用。它明确是旧工具成果交接，不宣称伪造了上游原生 fork。
普通恢复保持原账本和会话；不能将这种隔离验收当作常规任务的自动重跑机制。
笔记空间由宿主在外层工具桥和内层组织资料组合中统一传递；来源授权仍绑定原任务。
内层不得重新固定到旧笔记空间，也不能通过关闭嵌套身份检查来容纳分支。集成检查
须实际穿过 `read_research_source` → 资料组合 → 来源恢复，包含权限撤销情形。

## 查询前置延迟

原词法查询反复扫描 `nodes` 元数据，但同表携带大块 `counts`，只选择几列也会
访问大数据页。现在由已验证发布的准备阶段，用 SQLite/FileLock 建立很小的
只读派生元数据表，发布文件本身不写入。后续只从该表读取位置、身份和长度；
词频、postings、子集IDF继续使用原算法和原发布。原文不复制。

投影绑定原文件身份，由运行时缓存目录管理；文件变化拒绝旧投影。SQLite提交
头的100字节参与身份检查，避免Windows连接未关闭时文件时间戳不立即更新。
这不是每次重新哈希全库。当前Java授权独立检查，缓存不授予访问权。
首次投影构建有成本，安排在无模型准备阶段；后续恢复复用已发布投影。
词法统计/元数据缓存与检索生命周期共同交接，不能只预热一个对象而查询另一个。
原生组织入口在启动模型前调用同一实例的 `prepare_retrieval`，把固定发布加载及
缓存证明读取留在无模型准备阶段。后续搜索复用该实例，不能在首个 MCP 搜索的
超时窗口内才冷加载，也不能以此为理由重新读取全部原文。

## 验证与限制

`scripts/engineering/replay_harness_tool_views.py <messages.json> --output <audit.json>`
读取本机导出的原始ToolMessage记录，不调用模型或业务工具、不写入研究状态。
回放验证候选数、逐项原文/位置/读取参数、来源状态、完整计算操作数与结果。

计算操作数的引句未在已绑定原文中出现时，错误回执可列出同一段内含该数值的近似行、表头和具体字符差异。模型自行选择引句并重新提交；多处匹配保留候选数和位置，比较回执不改变原校验或计算结果。
重复字段恢复后必须相等；冲突字段不自动选择。

实际记录回放：53条来源回执从1,803,526到830,104字符；5条计算回执从66,957到
34,145字符。这是同记录的离线模型视图比较，包含旧历史；不是实际付费token或
整段ACP历史减少量。已经写入原生历史的旧大回执不被偷偷改写，将由上游正常
历史/压缩机制处理。真实摘要忠实性和后续研究质量仍须单独验证。

继续条件：相关回归、真实记录回放、固定原生进程与MCP组合，以及当前容器的
查询前置检查通过后，才恢复原任务。保留失败、未知用量与原始提案；不因更换
工具展示重新生成成果，不用放大超时掩盖查询延迟。

## 已观察来源选择错误的跨进程反馈

来源 ID 的精确成员检查在组织资料上下文之外执行，避免上下文退出时将
`ToolException` 包装成异常组，最终只留下 MCP `Internal server error`。
未观察到的 ID 返回原请求 ID、明确错误码和 `browse_context(region="sources")`
入口；模型可继续通过 `read_saved_result` 获取准确标识或原始读取参数。
不按相似字符串选择原文，不把未命中认定为资料缺失。

恢复一个尚未完成的只读调用时，正常选择错误也作为持久回执交接给原生会话，
无需以一次成功读取作为恢复条件。权限、存储、连接等执行异常仍传播并阻断
后续模型派发；未知写入不自动重放。离线回放不改变模型提案或金融判断。

公开网页研究复用同一个 read_public_source。Exa 优先发现候选，Exa 出错、返回空列表，或定日核对后没有可展示候选时，才使用 DDGS 的通用网页搜索。两条路径的尝试均记录在回执中。定日任务先向原站核对明确的发布或更新日期（必要时再用托管读取），通过后才展示定位符；搜索摘要不作为引文。原文读取先使用受 URL 检查及大小限制的静态抓取，再按既有策略尝试托管抓取。此日期检查不提供整站历史快照。
定日检索回执区分提供方召回候选数与截止日核对后的计数；仅向作者披露淘汰原因的汇总，不展示期后候选的标题、地址或摘要。日期核对支持文章元数据和新闻稿标题旁的明确发布日期，看到晚于截止日的更新时间时仍予以排除。精确标题的可达性验收与模型自拟查询的召回效果分别记账。

同一执行绑定可通过 research_method_sections 指向已有方法中的具体章节，默认只披露摘要及 get_research_method 的准确参数。显式开启 include_method_section_text 才预先附上同一读取入口对应的正文。章节入口不增加工具权限；此配置用于比较方法披露方式，未配置的执行沿用原有输入。
公开检索无可见候选或原文未取回时，工具按已记录的具体原因返回行动入口。晚于截止日的候选附上“数据版本与当前研究入口”的准确读取参数，原站 403 提示原文访问被拒；混合原因分别呈现。Exa 限流与 DDGS 自报无结果分别保留，后者不计作第二次传输故障。没有日期排除计数的旧回执不推测日期原因。
同一任务首次收到明确 Exa 限流时，即使 DDGS 在同次查询中找到了候选，返回值也告知模型已切换。后续新发起的查询直接走 DDGS，日期核对和正文抓取也跳过 Exa 托管读取；原站读取照常使用。限流状态按任务身份保存在本地，停止、恢复或重启服务不清除此状态。另一任务仍优先尝试 Exa。普通超时、原站 403 和没有搜到结果不会触发这一切换。

日期限定的公开搜索可读取带文本层的 PDF。美国劳工统计局的归档候选遇到 403 时，对劳工部经济数据目录收录的系列，工具可核对同版 PDF 的发布机构标识、系列和解禁日期，再返回劳工部原件的独立文档入口。域名限制继续生效。截止日按公开日判断，读取回执记录实际 PDF 地址、提取方式和段落位置。此路径依赖搜索引擎返回对应候选，零召回不能据此判断资料未公开。

作者可在 check_quantitative_changes 中传入选定版本的局部 before/after 修改，按正式提交规则生成只读预览。有独立复核意见时，回执并排展示候选稿中的相关表述和意见摘录，包含相关收尾段的上下文。位置指向本次预览文本。文字相似度仅用于定位；低重合度的改写可能遗漏，匹配不构成矛盾认定或提交限制。

来源绑定计算允许中文原文中与汉字相邻的完整阿拉伯数字，例如“占比为6.1%”和“共有8户”。原引句、数字及来源身份保持不变；较长数字中的片段、拉丁字母或下划线标识符中的数字仍拒绝。该兼容只解决词法边界，不确认作者对单位、期间、分母或因果关系的解释。

恢复已结束的计算错误时，用原参数和该次调用前的成功来源执行当前确定性检查。仍失败的回执继续提供真实错误；已通过的另列当前检查结果、原调用参数和历史失败，明确尚未保存为正式计算。不得把历史拒绝继续表述为当前有效错误，也不得自动补写缺少的引句或把检查结果当作作者已提交成果。原始失败记录保持不变。

运维回放可以从早于最新失败的批次验证修复。工作台通过最新运行授权恢复，运维另行固定原执行的业务检查点、导出摘要和起点运行 ID。隔离分支首个恢复命令从起点运行的事件中读取失败调用 ID，与导入检查点中的回执核对后生成当前反馈。沿用原生会话时，在分支专用的 DSH_HOME 内保存截至同一轮结束的完整原生日志前缀，并向 ACP 提供日志原有的工作目录。来源权限、成果和费用仍走当前授权的执行入口。根图检查点使用 LangGraph 的空字符串命名空间。

有截止日的公开搜索支持直接核查已知 HTTPS 网址。将完整网址作为 search 的 query，工具沿现有地址检查与来源日期核验生成可读入口，再用返回的 document_id 读取原文。搜索引擎的 HTTP 状态、找到但未通过日期核验的候选计数，以及原站拒绝访问分别记入回执。美国人口普查局部分报告 PDF 只印发行年月；若对应的官方出版页有明确日期且链接该文件，可按出版页自身身份取证。文件版本与正文仍需独立核实。


有截止日、已授权公开联网并绑定美元任务预算的组织研究，使用同一个 `read_public_source` 入口。Exa 优先；没有通过截止日核查的候选时，依次尝试 DeepSeek Search 和 DDGS。缺少 DeepSeek 凭据时保留原路径。单一明确的 `site:` 查询限制也在本地检查。DeepSeek 返回的排名、摘要和索引日期不构成原文依据。DeepSeek Fetch 可辅助辨认首条结果的出版日期；仅在同一网址的原站 HTML 独立匹配标题、日期和正文开头时采用，不能凭托管 Markdown 认定跳转或引用来源。搜索核验与随后读取可复用同一会话有限缓存中的原站响应。

DeepSeek Search、Fetch 按非空成功响应分别计费，目前均为每次 $0.00075。使用同一任务预算先预留后结算；相同线程、同一请求复用账本，响应不明保留预留，不自动重发。该兜底不会保证原站可访问，也不保证纯自然语言查询把发布机构排在首位。依据：[DeepSeek Search 与 Fetch 接口](https://api-docs.deepseek.com/guides/search/)。
就业公报的发布日期以原件首页的 embargo 声明为准，兼容 BLS 使用的 “this release” 与 “this news release”。统计月份与发布日期分别保留。
有截止日的公开搜索中，明确点名密歇根消费者调查及月份、或美联储 SCF 及调查年份时，工具先查发布机构的分期目录。原件仍需独立核定日期并读取。密歇根初值、终值分别匹配，滚动数据表中的月份不能替代发布日期；SCF 的调查启动公告可用于核实预告安排，公告与正式结果分别按公开日期放行。目录不可用或无可核实的候选时沿原路径继续检索。目录导航不替作者判定结果是否发布。
