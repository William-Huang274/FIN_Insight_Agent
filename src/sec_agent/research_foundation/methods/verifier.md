# 研究与报告复核

版本：13。适用于独立检查者；本地 schema 检查不能代替语义复核。

交付对象先对齐：专家底稿按本专题成功条件验收，不要求每份底稿生成全报告或投资结论。除可读性外，核对摘要/正文与下游接收的结构化主张、条件、依据步骤和引用版本是否一致；脱离全文接收某条主张时，关键适用条件是否仍在。附注可承载详细说明，但不能是决定含义的限制唯一存放处。来源可回读、提交成功、作者自检、上级接受与独立复核分别确认；修订后一处正确不能替代其他关联位置已同步。问题交给负责该专题判断的专家Lead或原作者，不能依赖主Lead猜测补全，也不能为求字段齐全否定已有充分支持的有限结论。

## 执行顺序与交付

局部推理复核以具体论断及其实际依据为对象：先判断这些依据也能否出现在另一种解释下，再判断正文是否过早排除它。例：汇总周转天数稳定并不识别每个客户付款条件，渠道回款正常也不证明终端消化；产品结构变化与集团毛利率变化同现并不识别单项价格或利润率。指出多说的那一步、它对主回答的影响及可区分解释的信息。已有直接证据时承认其解释力，不要求每句话附带反例或把一处意见升级成全量复核。

专门核对多段证据组合后的含义：各自成立的数字不保证组合成立。检查期间、主体、分母及已实现/预测限定有没有在标题、表格或总结中丢失；季度构成与全年指引等不同口径不得默认拼接。负责人任务中的预查判断也要核验，不能因来自上游而接受。逐项对照任务成功条件和实际产物，检查正文中未列入claims的派生指标是否有计算回执；缺少相关检查不能写成全部完成。

1. 从原始用户题面和实际成果开始；作者委派的重点是检查线索，不替代原题范围。整稿复核同时检查“已有论断是否成立”和“调查是否足以回答原题”：样本覆盖的用户、场景、地区或商业模式能否支撑结论的适用范围，是否遗漏足以改变主判断的比较对象。无需穷举产品、地区或机械凑样本数；局部委派仍围绕所选关系及必要关联，不自动扩成整题研究。不以作者的思考记录或“已核验”标记替代检查。选影响结论的关键数字、比较和因果句回读实际依据。
2. 数值层：核指标名称、主体、正负号、单位、单季/累计/全年和实际日期；标准计算优先复用财务工具的结果及输入血缘。检查同比基数和利润率百分点，亏损转换避免机械增长率。
3. 解释层：明确“来源支持了什么、正文多说了什么”。由费用解释利润变化须使用费用增量；CFO/净利不等于客户回款率；现金流下降不等于现金耗尽。检查合并/分部、总额/增量、事实/目标的转换，不靠关键词判合格。
4. 时间与交付层：核财年先后及旧指引时效、段落编号和底稿引用映射，核正文/表格/图表是否引用同一计算结果。引用存在不等于它支持当前句子的经济含义。
5. 每项重大意见应说明原句或位置、依据与推断缺口、建议执行的动作，以及同稿哪些概括依赖它。动作可以是纠正事实/计算、撤回结论、缩小适用范围、补查具有区分力的依据，或重写受影响论证；不要只写“更谨慎”。例如少数样本不足以支撑总体判断，应要求补充可检验适用范围的比较，或收窄结论，并同步处理摘要与展望；不指定某个产品作为必查标准答案。诊断与建议解法分别受检验：替换数字须明确分子、分母和调整，未核实的替代解释仍是待查假设。作者可以用依据反驳或提出替代处置。发现计算错且工具可用就纠正并回读；以实际修订后的论证验收，不以作者接受建议或增加免责声明为通过条件。
6. 决定复核结论的可查缺口由本次检查继续核实，不因已经发现作者错误就结束调查。工具返回参数、定位或日期反馈时，自行调整读取或查询；遇到原站拒绝，沿出版者公告、正式归档和对应官方接口寻找同版依据。执行故障仍由宿主修复后接续，不能当成信息边界或仅转给作者。必要公开路径已核查而仍无法取得的材料，说明尝试和对判断的具体影响；不要求穷尽无关资料。提交时区分已完成发现与未决事项。复核意见也可能错，作者有新证据时重新核实并撤回不成立的意见。

检查关键主张是否由实际来源上下文支持，而非仅存在一个引用ID。核对主体、业务范围、日期、期间、币种、单位、定义及事实/目标/计算/推断的身份；原文数字即使正确也可能被用在错误的总体论证里。

同时检查过强结论和过强否定。未单独披露不等于未实现；来源称符合目标时，应保留这一有归属的陈述，而不把它升级为精确披露，也不降格成毫无实际兑现的信息。相似措辞不证明第三方与发行人、不同期间之间同口径；原稿中的限定语同样需要核查，不能默认它们正确。

用来源绑定计算器复核关键核算和分母、同比基数、合并/分部口径。非 SQL 原文可以支持明确标注的分析，不能单因它不是 SQL 就否认直接披露；计算结果也不能冒充公司原始披露。

对解释变化的桥接，明确区分本期总额和相对基期的变化量；先核对期间、单位、主体与定义，再运算。存量、流量、分部收入、对外收入不能仅凭名称相近直接比较。归因区分发行人明确解释、来源支持的研究推断和仍待验证的假设；原文有两个事实不等于原文证明二者存在因果。给出对应判断、原文定位及对主回答的影响；影响中心解释时，相关内容包括标题、摘要、章节顺序和结论，不以旧稿结构为验收边界。

既找过强因果、错误对比与遗漏限制，也找影响主结论却未经展开的解释。按用户要求的工作深度判断：晨报可以保留有归属的解释线索，专题报告若依靠该解释排除另一原因或推导投资影响，应核对原始依据和必要的中间关系。对承担论证责任的媒体解释或社交发言，核对消息原件、相对先前预期的变化、从变化到业务或资产的传导；区分原报道提供的依据和作者自行追加的推断。需要具体方法时读取 event_policy 的“媒体解释的来源链与求证”。

将发现说到足以推动下一步研究：定位哪条结论依赖缺失关系、当前来源究竟支持什么、不同查证结果会怎样改变这条结论。若关键原件可读且在授权工具范围内，先做必要核对；还未核实的替代解释应作为待查问题，不写成给作者照抄的答案。不能只建议给原句加上“媒体认为”或“尚不能证明”，也不要求把所有背景材料研究一遍。评价修订时，看作者是否取得了区分解释的新观察，或正确界定仍有依据的使用范围；免责声明变多不等于解释变充分。整体问题有没有真正回答，主判断是否与各节一致，最强反证是否公平呈现，图表是否与原值/期间/正文一致，都属于质量问题。

成文边界分层检查：正文应先给出材料能够支持的判断和依据，一般口径/覆盖细节可以用附注完整承载，不要求作者把同一免责声明加到每一段。会改变主判断的条件和反证必须在正文、必要时在摘要显现，不能藏在脚注。检查“未披露”“不能等同”“无法判断”是否有实际依据及明确影响，是否取消了本来成立的有限判断；检查未完成调查、工具失败、方法或材料准备不足是否被伪装成不可避免的信息边界。对这些情况指出应补的研究或应保留的判断，不以增加免责声明数量作为修复标准，也不为了可读性接受无证据结论。

“未披露、没有、可以排除”若决定估算或归因路径，检查这一前提本身：其依据是明确披露、覆盖检查还是未命中？优先读最可能推翻它的附注或原始段落，保留检查范围，不要求每次重搜全部资料。审查意见也须有依据；作者提供反驳时读原文，不将自己旧意见当权威。

复核可以针对成文前的关键分歧，也可针对已有稿件；不是每题必经两轮。返回具体判断、影响和依据，区分事实修正、关系缺口与中心解释变化，不另填分类表。对最重要的意见，把同稿中依赖该前提的概括一起定位，包括标题、摘要、投资含义及未改的结尾；不要把一个逻辑问题拆成许多独立措辞建议。若相关原件在合理的公开路径上尚未检查，指出具体欠缺的核查，不能把作者声称‘材料不足’直接当成已完成研究。也不要求穷尽所有公开资料：实际无法取得的合同或未来结果，与可查而未查的内容不同。你提出的替代机制也需要判别依据，不能把它写成作者照抄的标准答案。修订后优先检查实质变化和相关上下文，不重读全部历史，也不以零建议或接受意见数量验收。最终模型意见不替代用户产品验收。

重点抽查摘要与末段是否反转了正文已确认的会计分类或限制。预付款、融资定金和补助先核现金流归属，再判断FCF影响；税前与税后项目不能直接相扣作正常化利润。合同覆盖面、已签/计划比例及适用产品必须保持一致；新增产线投产时间不能单独证明此前价格不可能反转。将可修的读取/计算失败留给其责任环节，不允许在总结中改名为未披露。
