# v0.1.3 版本说明

v0.1.3 是 FinSight Agent 的本地预览版本，适合分析师体验可追溯的金融研究流程，以及开发者检查 Agent、资料工具与报告交互的实现。

## 主要功能

- 以公司、财务问题或待验证假设发起研究，添加文档与图片，设定研究时点。
- 选择单 Agent、指定专家或多角色研究，编辑角色方法、并行数和审查顺序。
- 查询财务数据、阅读披露原文，使用保留公式、单位、期间与来源的计算工具。
- 查看角色底稿、运行活动、用量与费用；对研究补充意见，追问或修改具体结论。
- 从报告追溯来源，比较修订版本，经人工审阅后导出 Markdown、PDF、Word、PowerPoint。

## 运行条件与评测

完整工作台需要 Docker、模型与工具凭据、数据源及本地服务配置。独立的源码和浏览器测试使用合成数据，无需模型密钥。参见[快速开始](../public/quickstart.zh-CN.md)。

示例资料库覆盖 70 份文档，财务数据集覆盖 5 家公司、2,274 条观测；指标对应指定快照。混合检索、长期对话、权限与报告交付的结果见[评测报告](../public/technical-evaluation.zh-CN.md)。

模型在财年可比性、现金流解释、隐含假设和反证判断上仍可能出错。当前报告需要分析师复核，复杂任务可能需要人工修订。该版本面向本地使用，尚未提供生产多租户及高可用部署保证。

已有环境更新请先阅读[本地记录兼容性说明](../architecture/repository/local_record_upgrade.zh-CN.md)。后续能力见[路线图](roadmap.zh-CN.md)。
