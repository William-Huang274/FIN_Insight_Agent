# 作者与复核分工及专题研究结构（拟议）

状态：已获用户确认，进入实现和干净新会话验证。基本指引与相关方法已替换；原生 harness 可由宿主开放按需独立调查/复核工具，沿现有只读工具和 Sol 计费服务执行。工程检查与真实研究表现分开登记。

## 总体选择

保留一个对完整答案负责的主作者。工具、委派及独立复核按需要使用，不恢复固定专家—双复核—Lead 流水线。复用工作记录、稿件版本、来源、计算、授权与预算。读取数、笔记数、假设数不是质量指标。

现有 event_policy 已教原件、变化与传导，verifier 已要求检查关键解释。不能再把它们扩写一遍，声称方法已解决；本方案重点是职责、调用时机和观点变化后的统稿。

## 分工

| 责任 | 工作输入与动作 | 产出及边界 |
| --- | --- | --- |
| 主作者（由任务配置） | 原问题、当前认识、证据和未决关系；选择会改变答案的疑问 | 对完整解释负责；可补证、反驳复核、调整中心、删除失去作用的数字和段落 |
| 按需调查（自行或委派） | 具体疑问、必要材料和工具；不是泛泛创建专家 | 发现、比较基准、依据和未决关系；不强制交一章可粘贴正文 |
| 独立判断复核（可用 Sol） | 具体论证或稿件准确版本、依据及用户要求的深度 | 核关系是否成立、是否缺一环、竞争解释能否区分；可补查，替代解释同样需证据 |
| 作者修订与统稿 | 复核者实际意见、新材料和受影响上下文 | 事实问题局部改；中心改变则重排必要章节，复用已有研究，不强制一次生成整篇 |
| 工具与持久化 | 准确入口、版本、成功结果和失败原因 | 保证执行与交接，不以自然语言规则替代政治、商业及市场判断 |

复核不必等全文写完。若一个分歧决定接下来查什么，可以先核该问题；已有稿件则使用现成局部/完整复核入口。这是两种时机，不是固定新增两轮。重大未决问题或新推断才值得定点再查，不自动循环到零建议。

另一项可配置分工是由 Sol 从空历史主持：自行初步调查与理解原题，委派 Flash 调查和起草，再由 Sol 审核、补证和最终成稿。委派草稿是建议成果，不直接发布；最终责任留在主作者，避免末尾再次转回较弱模型。此分工复用现有按需委派与原生会话，不作为所有任务必经流程。验收需分别观察主作者选取的范围、子任务实际调查、审核新增发现及最终正文；不能仅因换了主作者便宣称质量改善。

## 连续研究与统稿

时效性研究在形成主判断前，默认先建立与研究时点相符的事实背景；概念解释或限定材料任务不自动扩大成新闻调查。基础职责v15与research_loop v8替换旧的起点及收口指导：辨认可能过时的认识、发现近期变化、据此选择深入关系。新闻热度、搜索次数、最新一份资料日期不代表覆盖充分。连续追问只检查与新目标相关的增量，仍可在新发现后重选重点。

研究重点需检验最初线索是否只是最容易取得的材料；从个案走向较广判断时，比较对象用于检验适用边界。用户要作出的判断决定收口，新闻核清不自动等于投资问题已回答，也不强制展开到估值。方法用虚构运输/制造例题教学，不预置当前AI题的公司或结论；没有固定新闻收集角色、强制计划表或公司数量。

快速、常规、深入模式共有时点核验底线，区别是探索宽度、比较和验证力度。主作者可按需要使用既有独立调查工具；不得用读取条数代替研究质量验收。

作者在现有工作记录中更新当前解释、重要依据及最可能改变答案的未决关系，不要求额外填表。决定调查时考虑：不同结果将如何改变当前解释？问题不重要或证据已够即可结束，不要求穷举所有解释。

教学用不同于当前题的例子：设备公司下调订单展望。若因为自有工厂停产，同业可能承接；若因为共同客户取消资本开支，同业也可能承压。调查围绕机制区分，结果回来后改变行业解释。不能只把“拖累行业”改成“公司称可能拖累行业”。

复核意见区分事实错误、关系缺口及中心解释变化，使用已有发现结构，不新增分类表。说明哪条结论受影响、哪项观察能改变判断；不把“谨慎一些”当通用修法。作者接受或反驳均须有依据，不能以接受意见数量证明完成。

修订范围由观点变化决定。数字误写局部改；前提被推翻则允许重排标题、摘要、章节及资产结论。已有原件、计算、有效段落复用，分批保存不受阻。作者最终按论证组织正文，不按检查意见顺序拼接。撤回的算式、逐条答复和纠错过程留在版本说明。

现行方法进一步把三个研究对象分开：已发生的制度变化、未来措施概率、价格是否反映。政治教学使用权限—程序—替代路径的实例；经营比较选择风险条件不同、能够区分解释的对象，而非累加公司数量。作者先决定当前答案与主次，再选择编辑或重构；旧标题和摘要是历史内容，不预设为新稿框架。详细教学进入已有 `event_policy`、`writer`、`verifier`，基本指引与章节目录同步替换旧要求，不新增固定复核轮次或计划表。

工程验收关注作者是否真正拿到当前稿、意见和关联位置；研究验收仍需观察模型是否据此改变了主判断、保住有效强结论、消除未改段落中的旧总括并改善中文。离线回放不证明这些研究行为已经改善。新观测供运维分析重复调用与上下文规模，不将方法库、字符数或检查条数变成研究质量分数。

实现核对发现，报告修订入口曾仍要求“局部修改”，与上述范围不一致。本次替换该入口，并让复核者对决定结论的可查缺口继续调查；查询反馈可自行处理，执行故障先由宿主修复。真实验证从旧局部修订任务之前的已保存报告接续，属于同题开发验证，不宣称未见题迁移或研究质量已通过。

## 本题拟议研究结构

这是当前政治新闻专题的组织建议，不是已证明的答案，也不是所有题的固定目录；作者根据发现决定主次和章节合并。

1. **本次变化是否改变原来的判断。** 摘要给当前答案、最重要理由和影响使用的条件，不写修订流水账。
2. **政治增量。** 相对选前，权力、支持条件、程序及执行何处变化；只展开对答案重要的联邦/州级路径，不以表态数量代替推进判断。
3. **经营传导。** 变化先影响谁的哪项决策；按项目阶段、地理、替代选址、融资及采购承诺解释收入/成本/时点，不把不对应的容量比例当现金流冲击。
4. **市场解释。** 若解释当天行情对总题必要，查披露、相对先前预期的变化、时序和跨公司传导。当天归因与中期经营判断分别成立；前者不清楚不阻止后者有价值。
5. **资产含义。** 从单项暴露走到主体净影响，再区分经营变化与价格。没有估值研究，不冒充已经识别可交易机会。
6. **会改变判断的下一项观察。** 明确当前基准、变化与结论的关系，不列与正文无关的万能风险清单。

详细来源、计算和修订记录附后。失去论证作用的数字可以退出正文，保留原始记录。

## 拟替换位置及验收

- `agent_guidance`：作者对整体答案负责，替换重复的抽象更新认识要求，不增加常驻教材。
- `research_loop` / `event_policy`：具体教学关键疑问选择、判别性调查及结果返回原解释，替换重复原则。
- `verifier`：核重要解释是否展开，诊断和替代解释同样受证据检验，作者可反驳。
- `writer` 和既有修订交接：按观点变化选编辑范围，删除把局部修订误解为只能改标错句的指导。
- 不新增强制计划、固定专家数、必经复核或因果用词校验器。

按用户最新要求，验证从空研究历史的新会话开始，保留原题研究目的并稍改题面，不带旧稿、笔记、复核意见或人工诊断。先核对实际输入与工具定义。观察自主补证、是否合理委派、解释是否随证据改变、摘要与结论是否一致、有效强判断是否保留及新增错误。检索执行故障先修再续，成功结果和费用保留。当前题属于开发验证，不能用来宣称未见题迁移通过。
