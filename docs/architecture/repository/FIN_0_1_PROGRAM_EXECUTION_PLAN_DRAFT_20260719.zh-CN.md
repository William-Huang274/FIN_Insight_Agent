### S2：One-Cell Bounded Real Agent

1. 先 S1 one-cell，再 S2 真实质量；S2 未产生实质增益前不得扩三 Cell；
2. 每次修复必须定位最早错误 owner，并改变输入、route、Skill、Context 或可验证实现；同一 failure fingerprint 无新信息时停止；
